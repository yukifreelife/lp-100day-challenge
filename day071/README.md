# Day071 - Cafe & Roastery LP

街角の小さなスペシャルティカフェのLP。焙煎過程にこだわり、オリジナルブレンドやシングルオリジンを提供するこだわりのカフェ。

## コンセプト

「一杯のコーヒーが、あなたの日常を特別に」

- 豆の産地から焙煎までこだわり抜いた品質
- 焙煎機を見ながら味わえる店内体験
- 持ち帰り用パッケージのデザイン性

## ターゲット

- 25〜45代、男女問わず
- コーヒーにこだわりを持つ層
- カフェ探索好き、サードウェーブコーヒーファン
- お土産・ギフト需要

## 構成

1. **FV**: 焙煎機のメインビジュアル、キャッチコピー、営業時間
2. **About**: こだわりの焙煎、豆の産地紹介
3. **Menu**: ドリンクメニュー、フードメニュー、豆販売
4. **Gallery**: 店内・コーヒーの写真ギャラリー
5. **Access**: アクセス、営業時間、SNS

## デザインポイント

- カラー: ウォームブラウン系（#6f4e37）を基調
- フォント: Noto Sans JP
- レイアウト: 温かみのあるデザイン、焙煎のビジュアルを活かす
- インタラクション: スムーズスクロール、パララックス効果

## 技術

- HTML5
- CSS3（CSS Variables, Grid, Flexbox）
- Vanilla JavaScript（スムーズスクロール、フェードインアニメーション）
