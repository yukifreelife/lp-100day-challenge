## 詰まり（1つ）
- VSCodeのターミナルで Codex を使ってサイト修正を行った際、
  **Hero画像が表示されない／レイアウトが崩れる不具合**が発生した。
- 原因：
  - Codexが生成したCSS差分の一部が欠落していた
  - 画像を `<img>` に切り替えたが、親要素の高さや `object-fit` の前提が揃っていなかった
- 対応：
  - 差分をそのまま適用せず、**一度却下**
  - 不足している要件（影響範囲・CSSスコープ・画像の扱い）を明文化して再指示
  - ターミナル操作・Codex設定を整理し、**Codexが正しく使えない状態を自力で解消**
- 結果として、  
  **「AIがうまく動かないときに、人間側で立て直す力」**が身についた。

   - ヒアリング用メタプロンプト作成
   - 要件定義・前提条件の整理

2. **方向性が固まったら**
   - ChatGPT（Thinkingモード）で  
     **Codexに投げるための「実装用メタプロンプト」**を作成

   - HTML / CSS を一気に生成
4. **ChatGPT（auto）＋手動**
   - 差分レビュー
   - 表示崩れ・構造ミスの修正
   - 微調整・CRO視点での改善
