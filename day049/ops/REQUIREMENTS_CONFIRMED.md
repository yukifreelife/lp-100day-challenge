# REQUIREMENTS_CONFIRMED

## 目的
- `確定 / 保留 / 含まない` を明確にして、口頭期待の混入を防ぐ。

## 確定
- 主目的:
  - 製造業の経営者 / 総務向けに、初回相談申込につながる入口LPを作る
- 副目的:
  - 何を相談できるかを分かりやすくする
  - 製造業向け支援であることを伝える
  - スマホで見やすくする
  - クライアントが自力で原稿を一から整理しなくても進められる状態にする
- 原稿支援の前提:
  - 素材や事実関係はクライアントが共有し、LP用の整理と本文たたき台は制作側で作成する
- 現時点で共有済みの素材:
  - 訴求優先順位
  - 事例 2 件の最終版に近い元情報
  - 事例ごとの掲載可 / 避けたい表現ルール
  - プロフィール元情報と避けたい見せ方
  - 既存サイト URL
  - 問い合わせフォーム URL とフォーム導線補足
  - 流用したい考え方 / 参考にしないでほしい方向性
  - 初回相談後の流れで誤解なく伝えたい点
- 受注判断時に必要なこと:
  - 金額そのものだけでなく、何がどこまで含まれ、どの条件で追加対応になりやすいかが明確であること
- 主導線:
  - 問い合わせフォーム経由の初回相談申込
- フォーム運用の前提:
  - 既存の Contact Form 7 を使い、日程調整はメールで行う
  - 現時点ではフォーム項目自体の大きな見直しは行わず、案内文や導線の見せ方で調整する
- 訴求優先順位:
  - 1位: 製造業の採用課題を、まず整理できる相談先であること
  - 2位: 採用専任者がいない会社でも相談しやすいこと
  - 3位: 求人原稿だけでなく、見学導線や発信、採用ページまで含めて見られること
  - 4位: いきなり大きな施策提案ではなく、現状整理から入ること
  - 5位: 初回はオンラインで相談しやすいこと
- ターゲット:
  - 従業員20〜70名程度の製造業
  - 経営者
  - 採用を兼任する総務担当者
- 価値訴求の核:
  - `何から見直せばいいか分からない製造業の採用課題を、まず整理できる`
  - `サービス一覧` ではなく `まず相談して整理できる入口` として見せる
  - ファーストビュー / CTA では `コンサル感` を強く出しすぎず、`状況整理から相談できる` 印象を自然に伝える
- 事例掲載の前提:
  - 社名は非公開とし、`愛知県内の部品加工会社` `東海エリアの小規模製造業` 程度の匿名表現で扱う
  - 応募数、採用人数、改善率などの具体数値は出さない
  - `応募が増えた` `採用成功` `短期間で成果` などの断定表現は避ける
  - `導線整理` `優先順位整理` `方向性整理` `見せ方整理` を中心に表現する
- プロフィール表現の前提:
  - `相談しやすい` `採用の全体像を整理してくれる` `製造業の実情を理解してくれそう` という印象を優先する
  - `製造業の事情を踏まえて現実的に相談に乗ってくれそう` と感じる見せ方を優先する
  - `実績豊富なコンサルタント` `何でもできます` のような強い打ち出しは避ける
- CTA温度感:
  - 主CTA候補は `採用課題について相談する` `初回相談を申し込む` `採用課題の整理相談を申し込む`
  - `今すぐ無料相談` `今すぐお問い合わせ` `無料コンサル受付中` などの強い表現は使わない
- 初回相談後フロー:
  - フォーム送信後、すぐに提案や見積りが出るわけではない
  - まずはオンラインで 30〜45 分程度の状況整理を行う
  - 初回相談内で課題や優先順位を整理し、必要に応じて個別提案へ進む
  - 相談したら必ず契約になるわけではないことを安心感のある形で伝える
- 初稿確認で特に見たい点:
  - 表現の強さ
  - 事例の見せ方
  - 相談後の流れの伝え方
- 公開時成功条件:
  - 2026年4月中旬を理想、遅くとも2026年4月後半の広告開始前に公開できる
  - `誰向けで、何を相談できるか` が一読で分かる
  - 問い合わせフォームへ自然に遷移できる
  - CTA表現が軽すぎず、相談しづらすぎないこと

## 保留
- 保留項目:
  - CTA 計測の有無と導入経路
  - 公開後スポット相談の範囲
  - CTA 文言の最終採用案を初稿上でどれに寄せるか
  - 初回見積りに置く修正回数の前提
  - SWELL 上でサイドバーなし / 幅広め / ページタイトル表示調整がどこまで素直にできるか
- 判断待ち:
  - 初回制作にどこまで軽微修正を含めるか
  - 既存サイトで `この一文は特に残したい` という個別箇所の追加入力があるか
- 期限:
  - 構成確定前
  - WordPress 反映着手前

## 含まない
- 初回制作に含まないもの:
  - 広告運用
  - 取材込みライティング
  - 予約ツール導入
  - 事例ページの量産
  - 継続的な月次改善運用
- 別フェーズ候補:
  - 公開後のスポット改善相談
  - CTA / 計測整備
  - 予約導線の強化
  - 実績や事例の追加拡充
