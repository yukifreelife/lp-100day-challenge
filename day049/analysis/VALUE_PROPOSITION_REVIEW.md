# VALUE_PROPOSITION_REVIEW

## 目的
- 訴求、証拠、法務の弱点を整理する。

## 訴求
- 誰向けか:
  - 従業員20〜70名程度の製造業
  - 経営者
  - 採用を兼任する総務担当者
- 一番強い悩み:
  - 採用に手が回らず、何から整えるべきか分からない
  - 応募が来ない理由を言語化できていない
  - 求人、見学導線、SNS、採用ページのどこに手を入れるべきか判断できない
- 提供価値:
  - 製造業に合わせた採用支援を相談できる
  - 無料相談を入口に、現状課題の整理と打ち手の見立てを受けられる
  - 単発サービス販売ではなく、状況に合わせた支援を組み立ててもらえる

## 証拠
- 実績:
  - 匿名事例なら掲載できる可能性あり
  - 求人原稿改善や会社見学導線整理の支援経験あり
- お客様の声:
  - 形式化された声は少ない
- 写真 / 素材:
  - 未確認
  - 製造業向けらしさを出す素材不足の可能性あり

## 法務 / 表現
- 注意点:
  - 実績や改善効果の表現は根拠確認が必要
  - 採用成果を断定する見せ方は避ける
- NG表現:
  - 確実に採用できる
  - 必ず応募が増える

## 改善メモ
- `何をしてくれる人なのか分かりにくい` を解消するには、サービス説明より `無料相談で得られること` を前面化した方がよい
- `製造業向け` は肩書きだけでなく、よくある課題理解、支援内容、事例のいずれかで証明する必要がある
- 証拠が少ない場合は、実績を盛るよりも `対応範囲` と `相談の流れ` を具体化する方向が安全
- 予算10万円前後の初回LPでは、`入口の整理` を優先し、個別サービスの深掘りや大量実績掲載は後回しが妥当
- LPの中心メッセージは `製造業の採用、何から整えるべきか分からない会社向けの無料相談` が有力
