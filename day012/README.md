## 詰まり（1つ）
- CSSを append-only で調整してきた結果、  
  **同一セレクタの重複定義や後勝ちルールが増え、意図しない配色が発生**した。
  - 対応：構造を壊さない前提で、セクション単位・コンポーネント単位で指定する運用に切り替え。
  - 次回、style.css の整理（統合・最適化）を行う予定。

## 学び（1行）
- ダークトーンのLPでは、**背景色を切り替えすぎない方が可読性と没入感が高い**。
