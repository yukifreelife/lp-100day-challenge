診断で見るポイント

“応募が止まる理由”を、情報・信頼・摩擦の3つで切り分けます（デモ）。

i

情報の不足

  • 仕事内容・期待役割が曖昧で、応募後のイメージが湧かない
  • 必須要件 / 歓迎要件の線引きが不明で、自己判断で離脱
  • 選考フロー・期間が見えず、不安が勝つ
  • 1日の流れ / チーム体制 / 使用ツールが無く、解像度が上がらない
✓

信頼の不足

  • 会社概要はあるが、“なぜ今この採用か”が伝わらない
  • 実績や数字、プロジェクト例がなく、判断材料が足りない
  • 働く人の情報（写真/声/価値観）が薄く、安心材料にならない
  • よくある質問が無く、懸念が解消されない
→

導線とフォーム摩擦

  • CTAが目立たない / 少ない / 文言が弱く、行動の後押しが足りない
  • “応募”しかなく、ライトな導線（カジュアル面談等）が無い
  • フォーム項目が多い・必須が多い・入力補助が無く、離脱が増える
  • 送信後の案内が不明で、最後の不安が残る

フォーム最小の例：メール / 採用LP URL / 職種（＋任意で会社名・担当者）
