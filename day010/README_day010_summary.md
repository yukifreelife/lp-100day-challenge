## day010C'（既存LPベース：LP改善・CV導線設計の無料相談）

### 特徴（A'との違い）
- SPナビが `<details class="nav-drawer">` 方式（JSなしで開閉できる）
- `../assets/css/base.css` を参照するため、**フォルダ階層が変わるとCSSパスが切れる可能性**あり

### ⚠ 明確なバグ（修正推奨）
- `style.css` の末尾付近に、**余計な `}` が1つ**入っている場合があります。  
  → `@media (prefers-reduced-motion: reduce) { ... }` の直後に `}` がもう1個あるなら削除してください。

### 簡易チェック（ブラウザで確認）
- PC/SPそれぞれでナビが表示され、クリックでページ内移動できる
- `<details>` ナビが開閉でき、スクロールしてもメニューが視認できる
- CSSの崩れ（突然の無効化・レイアウト破綻）がない  
  ※崩れる場合は上記「余計な `}`」が原因のことが多い
