## P0改善（即座に効果が出る）

### 1. CTA文言改善 [CRO]
**現状**: 「ご予約をご確認ください」
**改善案**: 「今すぐ席を確保する」
**期待効果**: CTR +15〜25%

```html
<a href="#reservation" class="btn btn-primary">
    今すぐ席を確保する
    <span class="btn-subtext">月160席のみ・残席状況確認</span>
</a>
```

### 2. ソーシャルプルーフ視覚化 [Copywriting]
**現状**: 4.9評価が構造化データのみ

```html

        <span class="stat-number">★★★★★</span>
        <span class="stat-label">4.9（156件）</span>
    </div>
    <div class="stat-item">
        <span class="stat-number">80%</span>
        <span class="stat-label">リピーター率</span>
    </div>
</div>
```

**現状**: `G-PLACEHOLDER`
