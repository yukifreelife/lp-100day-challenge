## 詰まり（主に2つ）
- **Git**：直前コミットの取り消しはできたが、**直前以外のコミットを取り消す手順が未整理**（Reset/Revert/rebaseの使い分けが分からない）  
  → こまめなコミットが“セーブデータ”として有効だと実感。次回は「戻し方の種類」を整理する
- **VSCodeのAI利用**：VSCode上で**codex / claude がどちらも使えなかった**  
  → 原因は、VSCodeで使える状態までの**セットアップ（拡張、ログイン、キー/設定）未完了**の可能性が高い

## 学び（1行）
- 差分運用は「小さいコミット × 戻せる手順 × 変更範囲の固定化」で再現性が一気に上がる
