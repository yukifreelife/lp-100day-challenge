初心者でも続く 食事管理チェックリスト（3か月ボディメイク用）

作成者: 3か月ボディメイク伴走プログラム
対象: 20代後半 - 40代前半の忙しい社会人
目的: 無理なく続く食習慣を3か月で身につける

----------------------------------------
0. 使い方（最初にお読みください）
----------------------------------------
1) 毎日、できた項目にチェックを入れます。
2) 1日で全部できなくても問題ありません。
3) 週末に「できた数」を見て、次の1週間の重点を1つだけ決めます。
4) 体重よりも、行動の継続を優先します。
5) 迷ったら「完璧より継続」を選びましょう。

評価の目安:
- 0 - 3個: まずは生活リズムを整える週にする
- 4 - 6個: 良いペース。無理なく維持
- 7個以上: とても順調。この調子で継続


----------------------------------------
1. 毎日の基本チェック（Daily 10）
----------------------------------------
[ ] 1. 朝食または午前中に、たんぱく質を1品入れた
[ ] 2. 毎食のどこかで野菜か海藻かきのこを食べた
[ ] 3. 主食量を「こぶし1つ分」目安で調整できた
[ ] 4. 間食は「時間を決めて」食べた（だらだら食べを避けた）
[ ] 5. 甘い飲み物を減らし、水・お茶を選べた
[ ] 6. 夕食は寝る2 - 3時間前までに済ませられた
[ ] 7. アルコールは量を決めて飲めた（休肝日を意識）
[ ] 8. 外食時に「揚げ物 + 大盛り」を避ける選択ができた
[ ] 9. 食事を5分以上かけて、落ち着いて食べられた
[ ] 10. 1日の最後に、明日の食事イメージを1つ決めた

メモ欄:
- 今日うまくいったこと:
- 今日つまずいたこと:
- 明日やること1つ:


----------------------------------------
2. つまずきやすい場面の対処チェック
----------------------------------------
[ ] 残業で遅くなる日は、先に軽食（プロテイン・ヨーグルト等）を準備した
[ ] コンビニでは「主菜 + 副菜 + 主食」の順で選べた
[ ] 空腹が強すぎる前に、計画した間食を入れられた
[ ] 会食前に水を1杯飲み、食べ始めをゆっくりにできた
[ ] ストレス時に「食べる以外の対処」を1つ実行した（散歩・入浴など）
[ ] 休日の食事時間が崩れすぎないよう、起床時刻を意識した


----------------------------------------
3. 1日の簡単テンプレート
----------------------------------------
朝:
- 例) おにぎり1個 + ゆで卵 + 味噌汁
昼:
- 例) ごはん普通盛り + 焼き魚 or 鶏肉 + サラダ
夜:
- 例) 主菜1品 + 野菜2品 + 主食少なめ
間食:
- 例) ギリシャヨーグルト / 素焼きナッツ / プロテイン

ポイント:
- まずは「量」より「抜かない」ことを優先
- たんぱく質は毎食に小さく分けて入れる
- 完璧を目指さず、前日比で1つ改善

----------------------------------------
5. よくある質問（短く確認）
----------------------------------------
Q. 毎日チェックできない日があります。
A. 問題ありません。空白があっても、再開できれば継続です。

Q. 体重がすぐに減りません。
A. 先に行動が整い、その後に体型変化が出るのが一般的です。

Q. 外食が多くて不安です。
A. 外食でも「主菜を確保」「主食を調整」「揚げ物頻度を下げる」で十分効果があります。

6. 最後に
----------------------------------------
このチェックリストは「短期間で追い込む」ためではなく、
3か月後も続けられる土台をつくるためのものです。

できた日を増やすより、「やめない日」を増やしましょう。
あなたのペースで大丈夫です。
