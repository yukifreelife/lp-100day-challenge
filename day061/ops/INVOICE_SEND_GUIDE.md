# INVOICE_SEND_GUIDE

## 目的
- 請求書送付のタイミング、方法、フローを標準化する
- 請求書関連のトラブルを防ぐ

## 送付タイミング

### 基本ルール
- **完了挨拶の2〜3日後**に送付
- 完了挨拶への返信有無に関わらず、このタイミングで送る
- 土日を避ける（平日送付が望ましい）

### タイミング早見表

| 完了日 | 完了挨拶送付 | 請求書送付 |
|---|---|---|
| 月曜日 | 月曜日 | 水〜木曜日 |
| 火曜日 | 火曜日 | 木〜金曜日 |
| 水曜日 | 水曜日 | 金〜月曜日 |
| 木曜日 | 木曜日 | 月〜火曜日 |
| 金曜日 | 金曜日 | 火〜水曜日 |

### 金額帯による調整

| 金額 | 送付タイミング |
|---|---|
| 〜5万円 | 完了メールに添付可 |
| 5万〜30万円 | 2〜3日後に別メール |
| 30万円〜 | 前金（30〜50%）＋残金納品後 |

## メール構成

### 件名パターン
```
【請求書】案件名について（会社名 様）
請求書：【案件名】のご請求について（会社名 様）
```

### 本文必須項目
1. 挨拶（「お世話になっております」）
2. 直近の言及（「先日は完了ありがとうございました」）
3. 請求書添付の明示
4. 請求金額
5. お支払期限
6. 振込先情報
7. 振込手数料負担の明示（「貴社負担」が一般的）
8. 領収証の発行有無

### 添付ファイル
- 請求書（PDF形式）

## お支払期限

### 一般的な設定
- **納品日から30日〜60日後**が主流
- 中小企業向け: 30日後が一般的
- 大企業・官公庁: 60日後〜月末締め翌月末払い

### 今回の設定
- お支払期限: **納品日から30日後**
- 理由: 中小企業向け案件のため

## 入金確認後のフロー

### 入金確認時
1. 入金を確認したら、お礼メールを送る
2. 領収証の依頼があれば、PDFを送付

### お礼メール（テンプレート）

```
件名: お支払いの確認（請求書No. XXX）

秋山様

お世話になっております。

本日、お振込を確認いたしました。
ありがとうございました。

領収証が必要であれば、PDFにてお送りいたします。
ご希望の場合は、ご返信いただけますと幸いです。

今後とも、よろしくお願いいたします。
```

### 未入金時の対応

| 期限経過 | アクション |
|---|---|
| 期限日 | 何もしない（振込手続きの時間を与える） |
| 期限日+3日 | リマインダー送付 |
| 期限日+7日 | 電話で連絡 |
| 期限日+14日 | 法的手続の検討 |

### 消費税の取り扱い
- 10% 対象（請負工事・ソフトウェア等）
- 免税対象（デザイン料等の場合もある）→ 要確認

## トラブル防止

### 事前合意
- 請求書の発行タイミングを契約時に明示
- お支払期限を契約時に合意
- 振込手数料負担を明示

### 記録
- 請求書送付日を記録
- 入金日を記録
- 未入金時のリマインダー履歴を記録
