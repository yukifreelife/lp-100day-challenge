- **目的**: 採用課題の整理相談への問い合わせ獲得

## 評価視点

### 1. デザイン（ビジュアルデザイン）
- **カラースキーム**: 色の選択、組み合わせ、ブランド適合性、トーン＆マナー
- **タイポグラフィ**: フォント、サイズ、ウェイト、行間、可読性、階層
- **余白**: 余白の使い方、呼吸感、情報密度、リズム
- **コントラスト**: 明度差、視認性、アクセシビリティ（WCAG準拠）
- **画像**: 選定、切り取り、品質、トーンの一貫性、実在感
- **全体の印象**: プロフェッショナルさ、親しみやすさ、信頼性

### 2. UX/UI（ユーザー体験）
- **視覚的階層**: 情報の優先順位が目立つか、ガイドがあるか
- **情報設計**: 情報の順序、グルーピング、関連性、スキャナビリティ
- **ナビゲーション**: ページ内移動、目次、現在地の把握
- **ユーザビリティ**: 操作のしやすさ、迷いにくさ、直感性
- **アクセシビリティ**: 色コントラスト、フォントサイズ、キーボード操作
- **全体の一貫性**: デザインの一貫性、ブランド感、統一感

### 3. コピーライティング（ライティング）
- **キャッチコピー**: FVタイトル・サブタイトルの魅力度、明確さ、独自性
- **見出し**: セクションタイトル、ブロックタイトルの分かりやすさ
- **本文**: 読みやすさ、理解のしやすさ、長さ、リズム
- **訴求力**: ターゲットの心に響く表現、課題への共感
- **CTA**: 行動喚起の表現、温度感、具体的さ
- **一貫性**: 全体のトーン＆マナーの統一感
- **信頼性**: 信頼を獲得する表現、誠実さ、具体性

### 4. コンバージョン（CRO）
- **ファーストビュー**: 最初の印象、价值提案、興味付け
- **CTAボタン**: 配置、デザイン、表現、数、バリエーション
- **導線**: 問い合わせまでの道筋、障壁の有無
- **信頼形成**: 信頼を獲得する要素、社会的証明
- **フォーム**: 問い合わせフォームの有無、簡易性
- **緊急性**: 行動を促す要素、タイミング、希少性
- **フリクション**: 心理的・物理的ハードルの有無

### 5. モバイル
- **レスポンシブ対応**: ブレークポイント、グリッド調整
- **タップ操作**: ボタンサイズ、リンクのクリック範囲、タッチターゲット
- **文字サイズ**: モバイルでの可読性、拡大表示
- **画像**: 表示サイズ、読み込み、品質、アスペクト比
- **縦スクロール**: 情報の順序、スクロール量、ナビゲーション
- **コンテンツ配置**: モバイル最適化、優先順位
- **パフォーマンス**: 表示速度、読み込み時間

### 6. 技術
- **パフォーマンス**: 読み込み速度、LCP、CLS、FID
- **アクセシビリティ**: ARIA、alt属性、キーボード操作
- **SEO**: metaタグ、構造化データ、URL構造
- **コード品質**: HTML/CSSの妥当性、保守性
- **ブラウザ互換性**: 主要ブラウザでの表示

### 7. ブランド
- **トーン＆マナー**: 「コンサル感を出さない」現務的な雰囲気
- **一貫性**: 全体を通して統一された世界観
- **差別化**: 競合との違い、独自性
- **親しみやすさ**: ターゲットに寄り添った表現
- **信頼性**: 製造業の実情を踏まえた現実感

## 評価出力形式

### 全体評価
- **総合評価**: ★★★☆☆（5段階）
- **良い点**: 5つ
- **改善が必要な点**: 5つ

### 各視点の評価
各視点について、以下を報告してください：
1. 評価（5段階）
2. 良い点（各視点2〜3個）
3. 改善が必要な点（各視点2〜3個）
4. 具体的な改善案（可能であれば）

### 優先度別改善提案
- **重要度高（すぐ対応）**: 3〜5件
- **重要度中（時間があれば）**: 3〜5件
- **重要度低（余裕があれば）**: 2〜3件

### 最終的な推奨事項
1. 次に取り組むべき最優先事項
2. クライアントに共有すべき内容
3. 再構築の要否（Figma等の導入を含む）

## 使用方法
1. HTMLとCSSファイルを読み込む
2. プレビューURL（http://localhost:8081）をWebReaderツールで確認
3. 各視点から評価を実施
4. 評価出力形式に沿ってレポートを作成
