【1. 追加対応の線引きについて】
まず、以下のようなケースであれば、基本範囲内で進めやすいです。

・独自のページビルダーを使っていても、1カラムの固定ページが既存機能で作れる
・余白や見出しデザインの調整が、軽い設定変更や少量のCSS調整で収まる
・既存フォームをそのまま使い、案内文やボタン文言だけ調整する

逆に、以下のような場合は追加対応になりやすいです。

・ビルダーやテーマの制約が強く、レイアウト再現のために個別調整が多く必要
  → `+20,000円`
・テーマファイルや複数箇所にまたがる大きな調整が必要
  → `+20,000円`
・フォーム項目自体の変更や、導線そのものの見直しが必要
  → `+20,000円`

ご質問にあった例でいうと、
・独自ページビルダーを使っている
  → それだけで追加にはなりません。制約の強さ次第です。
・テーマ側の余白や見出し調整に少し工夫が必要
  → 軽い調整なら基本範囲内です。
・フォームは既存のものを使えて、案内文を少し変えたい
  → 基本範囲内で収まりやすいです。

【2. 素材量の目安について】
今のところ出せそうとお書きいただいた
・事例2件
・プロフィールの元情報
・既存サイトURL
・フォームURL
があれば、基本的には初稿に進める想定です。

そのうえで、各事例について
・どんな会社か
・どんな課題があったか
・どこを支援したか
・その後どう変わったか
・どこまで掲載してよいか
が分かれば、本文たたき台はかなり作りやすいです。

逆に `+10,000円` の追加整理になりやすいのは、
・事例情報がかなり断片的で、複数回の聞き直しが必要
・プロフィールやサービス内容の元情報がほとんどない
・掲載可否の確認に何度も往復が必要
といった場合です。

現時点でお書きいただいた情報量であれば、基本範囲で着手できる可能性は高いです。

【3. 修正回数の数え方について】
ここでいう `1回` は、
`秋山様側で確認内容を一度まとめてご返答いただき、それを反映して戻すまで`
を 1回 と考えています。

たとえば、
・見出しや本文の修正点をまとめて返していただく
・こちらで反映して戻す
この1往復で 1回 です。

一方で、
・その同じ確認回の中での軽い補足
・誤字のご指摘
・短い意味確認
までを細かく 1回ずつ数える想定ではありません。

追加修正扱いになりやすいのは、
・一度反映した後に新しい論点が追加で出る
・方向性自体を改めて変える
・修正内容が分割して何度も届く
場合です。

【4. WordPress環境確認のために先に見たいもの】
最低限、以下があるとかなり判断しやすいです。

1. 固定ページ一覧の画面
2. 既存の固定ページ編集画面
3. フォーム編集画面、またはフォーム設定画面
4. 使用テーマ名が分かる画面
5. 現在のサービスページURL
6. 問い合わせフォームページURL

もしスクリーンショットをどこから取ればよいか分かりづらければ、
まずは
・固定ページ一覧
・固定ページ編集画面
・フォーム設定画面
・テーマ画面
の4つを見られれば十分です。

この整理でいうと、
・今お持ちの素材量なら、基本範囲で初稿に進める可能性は高い
・WordPress側も、軽い調整なら基本範囲内
・テーマ / ビルダー制約が強い場合だけ `+20,000円` 側に寄る
という見立てです。

もしこの4点で大きな違和感がなければ、
次は WordPress環境の確認に進んだうえで、正式見積りとして確定しやすい状態にできると思います。
