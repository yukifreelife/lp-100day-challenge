# ESTIMATE_SCOPE_MATRIX

## 目的
- 初回制作、公開支援、軽微修正、計測、レビュー、継続改善を切り分ける。

## スコープ表
| 項目 | 含む | 含まない | 別フェーズ候補 | 備考 |

| 原稿支援 | 掲載項目の整理、見出し案、本文たたき台、必要素材の洗い出し、既存原稿の整形 | 取材込みの長文ライティング、業界調査込みの深いコピー開発、完全ゼロベース原稿作成、キャッチコピーの大幅な再提案 | 原稿伴走 | 本文たたき台まで含む想定。事実確認と掲載可否判断はクライアント側確認が前提 |

## 契約条件メモ
- 初回10万円前後で進めやすい前提:
  - 1ページ構成
  - 素材は箇条書きや既存文面ベースで共有される
  - 既存 WordPress の固定ページとフォームをそのまま活用できる
  - 修正は各段階でまとめて行う
- 工数が変動しやすい要素:
  - WordPress のテーマ / ビルダー制約
  - 素材不足による追加整理やヒアリング
  - 修正回数の増加や大きな方向転換
  - 事例や実績表現の掲載可否調整
  - フォーム、計測、下層ページなどの追加要件
- 見積り時の修正前提:
  - 構成 / 原稿段階で 1〜2 回程度の整理修正
  - 公開前表示確認で 1 回の調整

## 見積り整理案
- 見せ方の基本:
  - `初回制作一式` として提案しつつ、内訳は工程ごとに見える形にする
- 内訳候補:
  - `LP構成・原稿整理`
    - 訴求整理、掲載項目設計、見出し案、本文たたき台、CTA整理
  - `WordPress反映・公開調整`
    - 固定ページ反映、フォーム導線接続、表示確認、公開前調整
  - `公開直後の軽微修正`
    - 誤字、短文調整、画像差し替え、リンク修正、軽い表示調整
- 想定金額帯:
  - 現時点の前提なら `9〜12万円前後` が目安
  - 条件が整えば `10万円前後` で組みやすい
  - WordPress制約や追加整理が増えると `12万円超` になりやすい
- 発注前に共有すべき注意点:
  - WordPress制約未確認のまま確定見積りにしない
  - 誰が最終確認者か曖昧だと修正往復が増えやすい
  - 公開後の改善提案は初回制作と切り分ける

## 概算見積りモデル
- 基本の概算見積り:
  - `100,000円（税込）`
- 内訳イメージ:
  - `LP構成・原稿整理`: 45,000円
  - `WordPress反映・公開調整`: 45,000円
  - `公開直後の軽微修正`: 10,000円
- この金額で進めやすい条件:
  - 1ページ構成に収まる
  - 素材の元情報が共有される
  - 既存 WordPress の固定ページと既存フォームを活用できる
  - 構成 / 原稿で 1〜2 回、公開前確認で 1 回程度の修正に収まる
- 追加対応の目安:
  - テーマ / ビルダー制約により反映方法の調整が増える: `+20,000円`
  - 素材不足で追加ヒアリングや整理作業が増える: `+10,000円`
  - 想定を超える追加修正: `1回あたり +5,000円`
  - フォーム項目や導線の見直し: `+20,000円`
  - 下層ページや大きな追加セクション制作: `+10,000円`

## 線引き具体例
- WordPress調整が基本範囲に収まりやすいケース:
  - 独自ページビルダーでも、1カラム固定ページが既存機能で作れる
  - 余白や見出し調整が軽い設定変更や少量のCSS調整で済む
  - 既存フォームをそのまま使い、案内文やボタン文言だけ調整する
- WordPress調整 `+20,000円` になりやすいケース:
  - ビルダーやテーマ制約が強く、レイアウト再現に個別調整が多く必要
  - テーマファイルや複数箇所の大きな調整が必要
  - フォーム項目変更や導線そのものの見直しが必要

## 素材量の目安
- 基本範囲で初稿に進めやすい目安:
  - 事例2件
  - プロフィールの元情報
  - 既存サイトURL
  - フォームURL
  - 各事例について `会社属性 / 課題 / 支援内容 / 変化 / 掲載可否` の最低限情報
- `+10,000円` になりやすいケース:
  - 事例情報が断片的で、複数回の聞き直しが必要
  - プロフィールやサービス内容の元情報がほぼない
  - 掲載可否の確認に何度も往復が必要

## 修正回数の数え方
- `1回` の考え方:
  - クライアント側で確認内容を一度まとめて返し、それを反映して戻すまでを `1回` と数える
- 回数に含めないもの:
  - 同じ確認回の中での軽い補足
  - 誤字指摘
  - 短い意味確認
- `追加修正` になりやすいケース:
  - 一度反映した後に新しい論点が追加で出る
  - 方向性自体を改めて変える
  - 修正内容が分割して何度も届く

## WordPress確認で依頼するもの
- 最低限ほしいもの:
  - 固定ページ一覧の画面
  - 既存の固定ページ編集画面
  - フォーム編集画面またはフォーム設定画面
  - 使用テーマ名が分かる画面
  - 現在のサービスページURL
  - 問い合わせフォームページURL
