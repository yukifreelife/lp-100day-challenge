# REQUIREMENTS_CONFIRMED

## 目的
- `確定 / 保留 / 含まない` を明確にして、口頭期待の混入を防ぐ。

## 確定
- 主目的:
  - 製造業の経営者 / 総務向けに、無料相談予約につながる入口LPを作る
- 副目的:
  - 何を相談できるかを分かりやすくする
  - 製造業向け支援であることを伝える
  - スマホで見やすくする
  - クライアントが自力で原稿を一から整理しなくても進められる状態にする
- 原稿支援の前提:
  - 素材や事実関係はクライアントが共有し、LP用の整理と本文たたき台は制作側で作成する
- 現時点で共有済みの素材:
  - 事例 2 件
  - プロフィール元情報
  - 既存サイト URL
  - 問い合わせフォーム URL
  - 流用したい表現 / 参考にしないでほしい方向性
- 受注判断時に必要なこと:
  - 金額そのものだけでなく、何がどこまで含まれ、どの条件で追加対応になりやすいかが明確であること
- 主導線:
  - 問い合わせフォーム経由の無料相談予約
- ターゲット:
  - 従業員20〜70名程度の製造業
  - 経営者
  - 採用を兼任する総務担当者
- 公開時成功条件:
  - 2026年4月中旬を理想、遅くとも2026年4月後半の広告開始前に公開できる
  - `誰向けで、何を相談できるか` が一読で分かる
  - 問い合わせフォームへ自然に遷移できる
  - CTA表現が軽すぎず、相談しづらすぎないこと

## 保留
- 保留項目:
  - CTA 計測の有無と導入経路
  - 匿名事例の掲載表現
  - 公開後スポット相談の範囲
  - CTA文言を `無料相談` `初回相談` `採用課題の整理相談` のどれに寄せるか
  - 初回見積りに置く修正回数の前提
  - SWELL 上でサイドバーなし / 幅広め / ページタイトル表示調整がどこまで素直にできるか
  - Contact Form 7 の現行項目のままで十分か
- 判断待ち:
  - 問い合わせフォームの使い勝手で十分か
  - 初回制作にどこまで軽微修正を含めるか
  - 事例 / プロフィールで掲載時に避けたい表現が追加であるか
- 期限:
  - 構成確定前
  - WordPress 反映着手前

## 含まない
- 初回制作に含まないもの:
  - 広告運用
  - 取材込みライティング
  - 予約ツール導入
  - 事例ページの量産
  - 継続的な月次改善運用
- 別フェーズ候補:
  - 公開後のスポット改善相談
  - CTA / 計測整備
  - 予約導線の強化
  - 実績や事例の追加拡充
