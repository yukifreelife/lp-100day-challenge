# WordPress固定ページ反映テンプレート

**使う場面**: 既存の WordPress サイトに LP や専用固定ページを反映するとき

## 目的
- 過去案件の固有事情ではなく、`反映前に何を確認し、どう進めるか` の型だけを残す。
- テーマ干渉、権限不足、受信先ミス、公開事故を防ぐ。

## 1. 事前確認

### ログイン / 権限
- [ ] 管理画面へログインできる
- [ ] 固定ページ編集権限がある
- [ ] メディアアップロード権限がある
- [ ] テーマ設定やカスタムHTMLに制限がないか確認した

### テーマ / ビルダー影響調査
- [ ] body class と `page-id-XX` を確認した
- [ ] 本文領域の幅制限クラスを確認した
- [ ] テーマ由来の font-family を確認した
- [ ] padding / margin / container 制約を確認した
- [ ] 自動で出るページタイトル、サイドバー、ヘッダー / フッターの有無を確認した
- [ ] ビルダー固有の wrapper や style 干渉を確認した

### 素材 / URL 差し替え
- [ ] 反映で使う画像 / アイコン / PDF の一覧を作った
- [ ] 反映後 URL を控える置換表を用意した
- [ ] 旧ドメインや検証URLが残らない確認方法を決めた

## 2. 反映作業

### ページ作成
- [ ] 固定ページを新規作成した
- [ ] タイトルを設定した
- [ ] スラッグを設定した
- [ ] 反映方式に応じて HTML / ブロック / ビルダーへ貼り付けた
- [ ] URL 差し替え済みの内容を反映した

### ページ設定
- [ ] 1カラム / サイドバーなし等のページ設定を確認した
- [ ] ヘッダー / フッター非表示が必要なら可否を確認した
- [ ] テーマ依存の表示設定がないか確認した

### 旧環境参照の除去
- [ ] 旧ドメインが残っていない
- [ ] 仮URL が残っていない
- [ ] 検証用文言が残っていない

## 3. テーマ干渉パッチ

### 確認ポイント
- [ ] 幅制限で LP が狭くなっていない
- [ ] 見出し / 本文フォントが意図せず上書きされていない
- [ ] ボタンやリンクのスタイルが競合していない
- [ ] テーマ余白でレイアウトが崩れていない

### パッチ原則
- [ ] `page-id-XX` 限定でパッチを当てる
- [ ] 全体テーマには触らず、対象ページだけに閉じる
- [ ] DevTools で実クラス名を確認してから書く

### 例: page-id 限定パッチ
```css
/* page-id-XX は実際の値に置換 */
.page-id-XX .entry-content,
.page-id-XX .entry-body {
  max-width: none;
  padding: 0;
}

.page-id-XX .lp {
  font-family: system-ui, -apple-system, "Segoe UI",
    "Hiragino Kaku Gothic ProN", "Yu Gothic", Meiryo, sans-serif;
}
```

## 4. 表示 / 技術確認

### 表示確認
- [ ] PC 表示を確認した
- [ ] SP 表示を確認した
- [ ] タブレット幅を確認した
- [ ] FV の改行、ボタン、画像比率を確認した

### DevTools 確認
- [ ] Network 404 = 0
- [ ] Console エラーなし
- [ ] 画像 / PDF / 外部リソースが 200 OK
- [ ] CTA の hover / tap 挙動に問題がない

- [ ] 修正期限または初回修正の扱いを明記した

## 6. 公開

### 公開前ゲート
- [ ] クライアントの公開OKを受領した
- [ ] 主要CTA が通る
- [ ] 法務リンクが開く
- [ ] 受信先 / 自動返信 / 通知先が正しい
- [ ] 公開後に cache / CDN purge が必要か確認した

### 公開後
- [ ] 保護設定を解除した
- [ ] 実URLで PC / SP 表示を確認した
- [ ] 主要導線の通し試験をした
- [ ] cache / CDN を使う場合、反映確認をした
- [ ] クライアントへ公開完了を連絡した

## 7. セキュリティ / 片付け
- [ ] 一時ログイン情報や保存パスワードを消した
- [ ] 作業メモと証跡を必要な場所へ残した
- [ ] 契約外の追加対応を混ぜていない

## 8. よくある問題

| 症状 | 原因の可能性 | 対処 |
| --- | --- | --- |
| CSS が効かない | ブロックやエディタ側で style が除去された | コードモード / 保存後 HTML を確認 |
| 画像が出ない | URL 差し替えミス / 拡張子違い | Network 404 を確認して修正 |
| 幅が狭い | テーマの container / max-width 制限 | `page-id-XX` 限定で解除 |
| フォントが違う | テーマ font-family 上書き | 対象ページ限定で再指定 |
| サイドバーが出る | ページ設定が 2 カラム | ページテンプレを見直す |
| 公開後に旧表示が出る | cache / CDN 未反映 | purge と再確認を行う |

## 残すべきテンプレ要素
- 権限確認
- テーマ / ビルダー干渉調査
- 旧URL 除去確認
- page-id 限定パッチ原則
- PC / SP / DevTools 確認
- プレビュー共有項目
- 公開前ゲート
- cache / CDN 反映確認
