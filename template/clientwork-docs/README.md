# クライアントワーク用補助テンプレ一覧
## Clientwork Docs

**使う場面**: チェックリストで参照される補助ドキュメントの正本を確認したいとき

## 目的
- `clientwork-checklists/` で参照している補助ドキュメントを template 配下で自立させる。
- `project-starter/` を改善するときの部品テンプレをまとめて持つ。

## 構成
- `ops/`
  - Intake、要件、見積、公開、クローズ用
- `analysis/`
  - 訴求整理、計測、レビュー、継続提案用
- `client/`
  - クライアント共有用
- `logs/`
  - handoff 記録用

## 使い方
- 新規案件開始の起点は `project-starter/` を使う。
- ここは補助ドキュメントの部品置き場として扱い、スターターや他テンプレを改善するときに参照する。
- チェックリスト内の参照名は、ここにあるテンプレ名と揃えて使う。
