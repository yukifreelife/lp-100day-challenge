##毎日の詳細マニュアル
1.昨日のdayXXXフォルダの、html,css,READMEをチャッピーに共有して、致命的な欠陥がないかを確認する
2.致命的な欠陥があれば、昨日のdayXXXフォルダの中でその見つかった修正点を修正する。
3.修正し終わったら、チャッピーと相談しながら「新しいLPのデザインの方向性」と、「今回改善したいことを1つ」決める。
4.昨日のdayXXXフォルダをコピーして、LPとREADEMEのスクショと、images内の画像ファイルを削除する。
5.フォルダ名、フッター、READMEの中身を今日の日付に変更する。templateフォルダ内のREADME.mdをコピペして差し替える

6.LPのデザインに合った画像をAdobeExpressの中から探す
7.チャッピーと壁打ちしながら、想定した「デザイン」の大枠に合わせて、文言・カラーを差し替える
8.チャッピーと相談しながら、今回1つ決めた「改善したいこと」を実装する
9.ChatGPTで「サイト名にあったファビコンを作ってください」と依頼し、生成後dayXXXディレクトリ直下に配置する
9.検証ツールを開いて、⌘+shift+Pでコマンドの検索ツールを出す
10.capture full size screenshot と打ち込んで、スクショをダウンロードする
11.README.mdに今日の成果と、冒頭に貼るラベルを記載して、記載が終わったらスクショを撮る
12.ダウンロードしたLPのスクショと、README.mdのスクショを、今日のdayXXXフォルダのに移動する。形式は、LPのスクショは、「dayXXX.html.png」README.mdのスクショは「dayXXX.png」にする
13.リベッターにLPとREADMEのスクショを添付して、今日の報告のつぶやきをする。
