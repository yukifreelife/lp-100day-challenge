# 公開前・本番反映前チェックリスト
## 09 Prelaunch Release Checklist

**使う場面**: 本番公開の直前に、仮設定や所有権、受信先、法務リンクを最終確認するとき

## この場面の目的
- 本番に仮設定を残さない。
- 公開してよい最低条件を機械的に確認する。

> 既存サイトへ反映する場合は、先に `10_backup_and_rollback_checklist.md` を通してから進める。

## 本番依存値
- [ ] 本番URL を確認した
- [ ] 主要CTA の遷移先を確認した
- [ ] フォーム受信先メールを確認した
- [ ] 自動返信文を確認した
- [ ] 個人情報取得同意文言や同意導線を確認した
- [ ] reCAPTCHA などのスパム対策要否と本番設定を確認した
- [ ] PDF URL を確認した
- [ ] 法務リンクを確認した
- [ ] 画像 URL を確認した

## 所有権 / 権限
- [ ] サーバー契約者を確認した
- [ ] ドメイン管理者を確認した
- [ ] GA4 所有者を確認した
- [ ] Meta Pixel 所有者を確認した
- [ ] フォーム通知先の管理者を確認した
- [ ] `06_account_access_and_ownership_checklist.md` が完了している

## 公開可否
- [ ] 作業者メールが本番受信先になっていない
- [ ] 仮URL や仮文言が残っていない
- [ ] 主要CTAが本番で押せる
- [ ] 法務リンクが開く
- [ ] 同意チェックや送信条件が本番で正常に機能する
- [ ] 検索エンジン公開設定が意図どおりになっている
- [ ] 本番URL に不要な `noindex` や検証用設定が残っていない
- [ ] キャッシュ / CDN を使う場合、公開反映または purge を確認した

## 通し試験
- [ ] `CTA -> フォーム開始 -> 送信 -> 通知受信` を本番相当で確認した
- [ ] 予約導線がある場合、`CTA -> 予約完了` まで確認した
- [ ] 自動返信がある場合、受信まで確認した
- [ ] PDF / 資料DL がある場合、`送信後 -> DL導線` まで確認した
- [ ] LINE導線がある場合、リンク先アカウントが本番で正しいことを確認した

## 公開時の証跡
- [ ] 公開URL を控えた
- [ ] スマホ表示確認をした
- [ ] iPhone / Android / Desktop のうち確認対象端末で表示確認をした
- [ ] 主要導線確認メモを残した
- [ ] 通し試験結果を残した
- [ ] キャッシュ / CDN 反映確認メモを残した

## 完了条件
- [ ] `PRE_LAUNCH_CHECKLIST.md` がすべて埋まった
- [ ] Blocked なしで公開判断できる
