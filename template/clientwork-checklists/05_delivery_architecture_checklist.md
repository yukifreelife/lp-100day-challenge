# 公開方式・実装方式確認チェックリスト
## 05 Delivery Architecture Checklist

**使う場面**: WordPressや既存サイトへの入れ方、公開方式、計測タグの入れ方を確認するとき

## この場面の目的
- 後から `このCMSでは想定どおり入らない` を防ぐ。
- 公開方式が決まるまで、運用上の約束をしない。

## 必須確認

> 権限・所有権・実ログインの確認は `06_account_access_and_ownership_checklist.md` で別途固定する。

### CMS / 公開環境
- [ ] CMS を確認した
- [ ] テーマ名を確認した
- [ ] ページビルダー有無を確認した
- [ ] 固定ページ / 投稿 / テンプレのどこに入れるか確認した
- [ ] WordPressバージョン要件を確認した
- [ ] アップロードファイルサイズ制限を確認した
- [ ] 必要なプラグイン特定（Contact Form 7等）を行った

### HTML / CSS / JS
- [ ] HTML の挿入先を確認した
- [ ] CSS の挿入先を確認した
- [ ] JS の挿入先を確認した
- [ ] 外部スクリプト制限の有無を確認した

### フォーム / 予約
- [ ] フォームの実装方式を確認した
- [ ] native form かプラグインか確認した
- [ ] 予約ツール導入の有無を確認した
- [ ] 予約完了地点があるか確認した

### 計測タグ
- [ ] GA4 の導入経路を確認した
- [ ] Meta Pixel の導入経路を確認した
- [ ] GTM の有無を確認した
- [ ] 誰がタグを入れるか確認した
- [ ] タグ管理をクライアント側で継続できるか確認した

## 言ってはいけないこと
- [ ] `管理画面で簡単に直せます` と先に言っていない
- [ ] `公開後すぐ分析できます` と先に言っていない

## 完了条件
- [ ] `DELIVERY_ARCHITECTURE_DECISION.md` に候補案とリスクを書いた
- [ ] 公開方式の未確定点を列挙した
- [ ] 権限確認が必要な箇所を `06_account_access_and_ownership_checklist.md` へ受け渡した
