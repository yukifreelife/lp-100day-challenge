# 請求・案件クローズ・継続提案チェックリスト
## 15 Close Retainer Checklist

**使う場面**: 請求、入金確認、案件完了、継続提案を整理するとき

## この場面の目的
- 請求とクローズを明確に終え、次フェーズ提案を曖昧にしない。

## クローズチェック
- [ ] 納品物を共有した
- [ ] クライアント受領を確認した
- [ ] 請求書を送付した
- [ ] 入金確認をした
- [ ] 最終返信を受けた
- [ ] 証跡データや通知メモの保管 / 削除ルールを決めた

## 請求事故防止
- [ ] 初回制作とレビューを混ぜていない
- [ ] 軽微修正の追加分を整理した
- [ ] 合意範囲外の追加対応を無償前提にしていない

## 継続提案チェック
- [ ] 継続時に何を見るか明文化した
- [ ] どの頻度で見るか明文化した
- [ ] どの指標で判断するか明文化した
- [ ] どこまで対応するか明文化した
- [ ] `継続できます` ではなく `継続すると何が分かるか` を示した

## 完了条件
- [ ] `PROJECT_CLOSE_LOG.md` を更新した
- [ ] 必要なら `RETAINER_SCOPE_MATRIX.md` を使って継続提案した
- [ ] 必要なら `16_handover_and_self_editing_checklist.md` を使って引き継いだ
