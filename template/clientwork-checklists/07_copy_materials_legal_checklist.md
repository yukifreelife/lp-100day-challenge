# 訴求・素材・法務確認チェックリスト
## 07 Copy Materials Legal Checklist

**使う場面**: 原稿整理、訴求整理、実績素材確認、法務確認を行うとき

## この場面の目的
- 訴求と証拠を固めてから見た目へ入る。
- 素材不足や法務不足を後工程の爆弾にしない。

## 訴求チェック
- [ ] 誰向けかを一文で言える
- [ ] 一番強い悩みを一つ選んだ
- [ ] 何を得られるかを一文で言える
- [ ] 無料相談 / 無料特典 / 資料DL の価値を言語化した
- [ ] 高単価でも納得する材料を整理した

## 証拠チェック
- [ ] 実績の掲載可否を確認した
- [ ] 実名 / 匿名の区別を確認した
- [ ] お客様の声の掲載可否を確認した
- [ ] 写真使用許諾を確認した
- [ ] before / after や定量実績の有無を確認した
- [ ] 実績数値や事例文言の裏取り元を確認した
- [ ] クライアントの記憶ベースだけで載せない方針を確認した

## 素材チェック
- [ ] 原稿の元ネタを受領した
- [ ] 写真素材の一覧を作った
- [ ] ロゴの有無を確認した
- [ ] アイコンや図解が必要か判断した

## 法務チェック
- [ ] 特商法ページの有無を確認した
- [ ] プライバシーポリシーの有無を確認した
- [ ] 問い合わせ先情報を確認した
- [ ] 業界上の NG 表現を確認した
- [ ] 成果保証や誤認表現を避ける方針を確認した
- [ ] 実績表現が誤認を生まないか確認した

## 完了条件
- [ ] 訴求、証拠、法務の弱点を `VALUE_PROPOSITION_REVIEW.md` へ反映した
- [ ] 素材不足が制作後半で初めて発覚する状態を避けた
