# 見積・スコープ・契約境界チェックリスト
## 04 Scope Estimate Contract Checklist

**使う場面**: 見積を出す前、提案範囲を切り分けるとき、契約条件を整理するとき

## この場面の目的
- 初回制作に全部載せない。
- `含む / 含まない / 別フェーズ` を見積上で明示する。

## line item 切り分けチェック
- [ ] LP制作・初稿を独立させた
- [ ] CMS移行 / 公開支援を独立させた
- [ ] 公開直後の軽微修正を独立させた
- [ ] 計測整備を独立させた
- [ ] 初回レビューを独立させた
- [ ] 継続改善を独立させた

## 含む / 含まない チェック
- [ ] 原稿支援を含むか明記した
- [ ] デザイン修正回数または期限を明記した
- [ ] WordPress 反映を含むか明記した
- [ ] 計測タグ実装を含むか明記した
- [ ] 公開後の微修正の範囲を明記した
- [ ] 広告運用を含まないことを明記した
- [ ] 継続レビューを含まないことを明記した

## 契約条件チェック
- [ ] 支払条件を明記した
- [ ] 検収条件または完了条件を明記した
- [ ] キャンセル時 / 中断時の扱いを明記した
- [ ] 著作権 / 制作データ / 計測データの権利を明記した
- [ ] サーバー / ドメイン / 外部ツール費用の負担者を明記した
- [ ] 外部サービスの実費が別か込みかを明記した
- [ ] 修正依頼の受付期限または窓口を明記した

## 価格事故防止チェック
- [ ] 予算に引っ張られて過剰に範囲を広げていない
- [ ] `今回の価格が関係構築価格か市場価格か` を自覚している
- [ ] 作業量の大きい項目に別 line item を切った

## クライアント説明チェック
- [ ] `そこまで別なんですね` に答えられる説明がある
- [ ] `どこまで含まれるか` を一文で説明できる
- [ ] `なぜ分けるのか` を工数・責任範囲ベースで説明できる

## 完了条件
- [ ] `ESTIMATE_SCOPE_MATRIX.md` に記入した
- [ ] 対外説明文面に `含む / 含まない` を反映した
