# 画像管理チェックリスト
## 17 Image Management Checklist

**使う場面**: 画像の差し替え、最適化、外部画像からローカル画像への変換を行うとき

## この場面の目的
- 画像ファイルの命名規則を統一し、管理・メンテナンスを容易にする
- ファイルサイズを最適化し、表示速度とユーザー体験を向上させる
- CCライセンス画像の適切な利用と権利関係を明確にする
- 外部画像からローカル画像への変換プロセスを標準化する

---

## 命名規則（Naming Conventions）

### ファイル命名ルール
- [ ] 小文字のみ使用する
- [ ] スペースはハイフン（`-`）に置き換える
- [ ] 記述的なプレフィックスを使用する:
  - `hero-` : FV/メインビジュアル画像
  - `section-` : コンテンツセクション画像
  - `thumb-` : サムネイル画像
  - `icon-` : アイコン画像
  - `bg-` : 背景画像

### 命名例
```
hero-main.jpg
section-service-01.jpg
thumb-case-01.png
icon-check.svg
bg-pattern.jpg
```

## 画像圧縮設定

### JPEG画像
- [ ] 品質: 60%
- [ ] プログレッシブ: ON
- [ ] 最大ファイルサイズ: 画像あたり200KB
- [ ] 使用ツール: TinyPNG / ImageOptim / Squoosh

### PNG画像
- [ ] シンプルなグラフィックはPNG-8を使用
- [ ] 透明度が必要な場合のみPNG-24を使用
- [ ] 最大ファイルサイズ: 画像あたり150KB

### WebP（オプション）
- [ ] モダンブラウザ向けにWebP検討
- [ ] レガシーブラウザ向けにJPEG/PNGフォールバックを用意

### SVG画像
- [ ] SVGOで最適化
- [ ] 不要なメタデータを削除
- [ ] SVGコードをミニファイ

---

## CCライセンス画像の利用

### 利用ルール
- [ ] ライセンス種類が商用利用を許諾しているか確認
- [ ]帰属表示（attribution）の要否を確認
- [ ] 画像ソースURLを記録
- [ ] プロジェクト内でライセンスタイプを文書化

### 帰属表示フォーマット
帰属表示が必要な場合:
```
Photo by [撮影者] via [ソース] (License: [ライセンスタイプ])
```

### 推奨CCソース
- Unsplash（無料、帰属表示不要）
- Pexels（無料、帰属表示不要）
- Pixabay（無料、帰属表示不要）
- CC0（クリエイティブ・コモンズ・ゼロ）

---

## 外部画像 → ローカル画像変換

### 変換プロセス
1. [ ] 外部画像をローカル環境にダウンロード
2. [ ] 命名規則に従ってリネーム
3. [ ] 目標ファイルサイズまで圧縮
4. [ ] HTML/CSS内のすべての参照を更新
5. [ ] 外部画像参照を削除
6. [ ] ローカル画像が正しく表示されるかテスト

### 検証チェックリスト
- [ ] すべての画像がエラーなく読み込まれる
- [ ] 画像品質が許容範囲内
- [ ] ファイルサイズが最適化されている
- [ ] 画像リンク切れがない
- [ ] レスポンシブ画像がすべてのデバイスで動作

---

## 画像保存

### ディレクトリ構造
```
/images/
  /hero/         - FV/メインビジュアル画像
  /section/      - コンテンツセクション画像
  /thumb/        - サムネイル画像
  /icon/         - アイコン画像
  /bg/           - 背景画像
```

### バージョン管理
- [ ] 最適化済み画像をgitに追加
- [ ] ソース/作業ファイルは.gitignoreで除外
- [ ] 画像ソースを別ファイルで文書化

---

## WordPress案件特有の注意事項

### アップロードファイルサイズ制限
- [ ] サーバーのアップロードサイズ制限を確認（デフォルト2MBなど）
- [ ] 制限を超える場合は事前に圧縮またはサーバー設定調整

### メディアライブラリ管理
- [ ] メディアライブラリ内でも一貫した命名規則を使用
- [ ] 代替テキスト（alt属性）を設定
- [ ] 画像タイトル・キャプションを適切に入力

---

## 完了条件
- [ ] すべての画像が命名規則に従っている
- [ ] すべての画像が目標ファイルサイズ内に収まっている
- [ ] CCライセンス画像の帰属表示が必要な場合は完了している
- [ ] 外部画像参照がなくなり、すべてローカル画像になっている
- [ ] すべてのデバイスで画像が正しく表示される
