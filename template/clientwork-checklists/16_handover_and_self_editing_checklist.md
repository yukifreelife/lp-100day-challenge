# 引き継ぎ・自己更新レクチャーチェックリスト
## 16 Handover And Self Editing Checklist

**使う場面**: 公開後または納品時に、クライアントへ運用引き継ぎを行うとき

## この場面の目的
- `自分でも直せる` を口約束で終わらせず、実際に触れる状態を確認する。
- 公開後の運用責任を曖昧にしない。

## 引き継ぐ内容
- [ ] どのURLを運用対象とするか共有した
- [ ] どこを自分で直せるか共有した
- [ ] どこは触らない方がよいか共有した
- [ ] 画像差し替え方法を共有した
- [ ] 文言修正方法を共有した
- [ ] 計測タグやフォーム設定は原則触らないことを共有した

## 実演確認
- [ ] クライアント本人が管理画面へ入れることを確認した
- [ ] クライアント本人が対象箇所を開けることを確認した
- [ ] テキスト修正の流れを確認した
- [ ] 画像差し替えの流れを確認した
- [ ] 間違って触ると危険な箇所を確認した

## 運用ルール
- [ ] 修正依頼の窓口を共有した
- [ ] 軽微修正と別対応の境界を共有した
- [ ] アカウントや権限を今後誰が持つか共有した
- [ ] 証跡データや通知メールの保管責任を共有した
- [ ] 必要な権限移譲が完了していることを確認した

## 完了条件
- [ ] `CLIENT_HANDOVER_GUIDE.md` などの引き継ぎ資料へ反映した
- [ ] クライアントが自分で更新できる範囲を理解している
- [ ] クライアントが必要権限を実際に受け取っている
