# 制作中の内部確認チェックリスト
## 08 Build Internal QA Checklist

**使う場面**: デザイン・実装中に、正本管理や最低品質を確認するとき

## この場面の目的
- 正本を一本化し、公開前に最低限の品質を満たす。

## 正本管理
- [ ] 実装正本は `current/` に集約している
- [ ] 日次ログに正本を複製していない
- [ ] 変更の根拠が `HANDOFF_LOG.md` に残っている

## LP最低品質
- [ ] 主要CTAが押せる
- [ ] スマホで大崩れしない
- [ ] 見出し階層が破綻していない
- [ ] 主要導線の文言が一貫している
- [ ] 法務リンクを置いている
- [ ] フォーム / 予約導線の文言が一致している

## 表示 / 導線 QA
- [ ] ファーストビューで対象と価値が伝わる
- [ ] CTA が上中下のどこかにある
- [ ] 相談後の流れまたは不安軽減要素がある
- [ ] 実績 / 証拠が最低限入っている
- [ ] 価格や価格の出し方が意図どおりか確認した

## 端末 / ブラウザ QA
- [ ] Desktop Chrome で主要表示と導線を確認した
- [ ] Safari 系ブラウザで主要表示と導線を確認した
- [ ] iPhone 幅で固定CTAやフォーム挙動を確認した
- [ ] Android 幅で表示崩れや改行崩れを確認した
- [ ] 確認対象端末 / ブラウザを `HANDOFF_LOG.md` に残した

## 完了条件
- [ ] 公開前に `PRE_LAUNCH_CHECKLIST.md` へ渡せる状態
