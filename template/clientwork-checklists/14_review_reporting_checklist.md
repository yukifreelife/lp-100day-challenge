# レビュー共有・レポート提出チェックリスト
## 14 Review Reporting Checklist

**使う場面**: 数値レビューや改善提案をクライアントへ共有するとき

## この場面の目的
- サンプル値ではなく、証跡付きで `事実 / 仮説 / 次アクション` を返す。

## 証跡チェック
- [ ] GA4 スクリーンショットまたは CSV がある
- [ ] Meta の補助確認メモがある
- [ ] フォーム通知件数メモがある
- [ ] 予約件数メモがある
- [ ] 外部流入要因メモがある
- [ ] 直接計測できない指標の代替証跡がある
- [ ] 証跡に個人情報が含まれる場合の取り扱いを決めた

## 分析チェック
- [ ] 対象期間を明記した
- [ ] 比較基準（前週 / 前月 / 公開前比など）を明記した
- [ ] 数値の事実だけを先に整理した
- [ ] 仮説と事実を混同していない
- [ ] LP上の課題と LP外課題を分けて書いた
- [ ] 改善案を 3段階で返せる状態にした
- [ ] `測れていないこと` と `今回言えないこと` を明記した

## 禁止
- [ ] 仮数値だけで納品扱いにしていない
- [ ] サンプル文面をそのまま実績文面にしていない
- [ ] 中間指標だけで最終成果を断定していない

## 完了条件
- [ ] `REVIEW_EVIDENCE_ARCHIVE.md` に証跡の置き場を書いた
- [ ] `CLIENT_MEASUREMENT_REVIEW_FINAL.md` を実数で埋めた
- [ ] 証跡の保管期間または削除ルールを決めた
