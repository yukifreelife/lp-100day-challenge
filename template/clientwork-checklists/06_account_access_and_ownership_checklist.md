# アカウント・権限・所有権確認チェックリスト
## 06 Account Access And Ownership Checklist

**使う場面**: 公開方式や計測方式を決める前後に、クライアントの実アクセスと所有権を確認するとき

## この場面の目的
- `所有者らしい` ではなく、`実際に誰が入れるか` を確認する。
- 前担当者 / 知人 / 作業者依存のまま本番運用しない。

## CMS / サーバー / ドメイン
- [ ] サーバー契約者を確認した
- [ ] ドメイン契約者を確認した
- [ ] WordPress 管理者アカウントの所有者を確認した
- [ ] クライアント本人が管理画面へログインできることを確認した
- [ ] もし本人が入れない場合、誰の管理か確認した

## フォーム / 通知
- [ ] フォームプラグインの管理者を確認した
- [ ] 通知先メールの管理者を確認した
- [ ] 自動返信の送信元 / 返信先を確認した
- [ ] 本番通知先が作業者や知人依存でないことを確認した

## 計測 / 広告
- [ ] GA4 の管理者を確認した
- [ ] クライアント本人が GA4 へ入れることを確認した
- [ ] Meta Business / Pixel の管理者を確認した
- [ ] クライアント本人または指定担当が Meta に入れることを確認した
- [ ] GTM を使う場合、管理者を確認した

## リスク確認
- [ ] 前担当者の個人アカウント依存がないか確認した
- [ ] 知人の暫定設定が残っていないか確認した
- [ ] 契約終了後に誰が運用を継続するか確認した
- [ ] ログインできない / 権限不足の箇所を一覧化した

## 完了条件
- [ ] クライアント側で保持すべき所有権を明文化した
- [ ] 実ログイン未確認の箇所を残したまま本番前提にしていない
