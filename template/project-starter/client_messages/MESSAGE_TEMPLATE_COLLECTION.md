# クライアントコミュニケーション メッセージテンプレート集

**目的**: クライアントとのコミュニケーションで頻出するパターンをテンプレート化し、品質と効率を向上させる。

**使い方**:
- 各テンプレートは案件状況に合わせて調整する
- {{変数}} の形式で案件固有の情報を埋め込む
- テンプレートは参考として使い、必ず文脈に合わせてカスタマイズする

## 1. 初期フェーズ

### 1.1 初回問い合わせ受領お礼

**使う場面**: クライアントから初めて連絡が来たとき

```
件名: Re: {{件名}}

{{クライアント名}} 様

はじめまして、{{自社名}}の{{担当者名}}と申します。

この度はお問い合わせいただき、誠にありがとうございます。
{{制作内容}}のご相談とのこと、承りました。

まずは、現在のご状況と課題について詳しくお伺いさせてください。
以下の点についてお教えいただけますでしょうか。

1. {{制作物}}の目的（何を達成したいか）
2. 現在の課題や悩み
3. ターゲット層
4. 希望納期
5. 予算感

この情報をもとに、最適なご提案をさせていただきます。

まずはお気軽に、{{問い合わせ内容}}について教えていただけますでしょうか。

よろしくお願いいたします。
```

### 1.2 スコープと予算の現実的な提案

**使う場面**: クライアントの希望と予算のバランスを提案するとき

```
件名: Re: {{件名}}

{{クライアント名}} 様

ご質問について、現時点での考えをお送りします。

## 制作範囲について

ご希望の{{制作内容}}につきまして、
予算感{{金額}}の範囲で実現可能なのは以下の範囲となります。

### 含むもの
- {{主要機能A}}
- {{主要機能B}}
- {{基本デザイン}}

### 含まないもの（追加費用工数か、別途検討）
- {{追加機能A}}
- {{追加機能B}}

### ご提案
今回は{{優先機能A}}に集中し、
{{追加機能}}は公開後の改善検討項目としておくのが現実的かと考えています。

## スケジュールについて

希望納期{{日付}}につきまして、
{{素材}}が{{タイミング}}までに揃う場合は、
{{日付}}頃の初稿ご提示、{{日付}}頃の公開が可能です。

ただ、こちらの確認が遅れる場合はスケジュールも後押しになる可能性があります。

まずは{{タスク}}から進めていただくのがスムーズかと思います。

ご検討のほど、よろしくお願いいたします。
```

## 2. 制作フェーズ

### 2.1 進捗報告

**使う場面**: 中間段階で現状を共有するとき

```
件名: Re: {{件名}}

{{クライアント名}} 様

お世話になっております。

現在の進捗についてご報告させていただきます。

## 完了した作業
- {{作業内容A}}
- {{作業内容B}}

## 現在進行中
- {{作業内容C}}（{{完了予定}}頃完了予定）

## 今後の予定
- {{次回作業内容}}を{{予定日}}頃から着手予定です

まずはこの方向性で問題ないか、ご確認いただけますでしょうか。

ご不明な点がございましたら、お気軽にお問い合わせください。

よろしくお願いいたします。
```

### 2.2 素材依頼

**使う場面**: クライアントから必要な資料を依頼するとき

```
件名: {{制作物}}制作に必要な素材のご共有

{{クライアント名}} 様

お世話になっております。

{{制作物}}の制作を進めるにあたり、
以下の素材をご共有いただけますでしょうか。

## 必要な素材

### 1. {{素材カテゴリA}}
- {{必要な項目1}}
- {{必要な項目2}}

### 2. {{素材カテゴリB}}
- {{必要な項目1}}
- {{必要な項目2}}

### 3. その他
- {{追加情報}}

可能でしたら{{日付}}までにご共有いただけますと、
スケジュール通り進行可能です。

素材が不完全な状態でも、たたき台として構いませんので
まずは現状をお送りいただいても問題ありません。

よろしくお願いいたします。
```

## 3. レビューフェーズ

### 3.1 フィードバック受領お礼

**使う場面**: クライアントから修正フィードバックを受け取ったとき

```
件名: Re: {{件名}}

{{クライアント名}} 様

お世話になっております。

ご確認とごフィードバックありがとうございます。

ご指摘いただいた{{点数}}点について、以下の対応を予定しております。

## 修正対応内容

1. {{修正項目1}}
   - 内容: {{具体的な修正内容}}
   - 予定: {{対応予定}}

2. {{修正項目2}}
   - 内容: {{具体的な修正内容}}
   - 予定: {{対応予定}}

3. {{修正項目3}}
   - 内容: {{具体的な修正内容}}
   - 予定: {{対応予定}}

## ご相談させていただきたい点

{{相談事項}}につきまして、
{{選択肢A}}/{{選択肢B}}のいずれかで対応可能です。

いかがでしょうか。

{{日付}}頃に修正版をお送りできる予定です。

よろしくお願いいたします。
```

### 3.2 修正完了通知

**使う場面**: 修正が完了したことを伝えるとき

```
件名: Re: {{件名}}

{{クライアント名}} 様

お世話になっております。

ご指示いただいた修正が完了いたしましたので、
修正版をお送りいたします。

## 修正内容

1. {{修正項目1}}
   - {{修正前}} → {{修正後}}

2. {{修正項目2}}
   - {{修正前}} → {{修正後}}

## ファイル

- {{ファイル名}}: {{ファイルの説明}}

ご確認のほど、よろしくお願いいたします。
```

## 4. 公開フェーズ

### 4.1 納品通知

**使う場面**: 最終成果物を納品するとき

```
件名: {{制作物}}のご納品

{{クライアント名}} 様

お世話になっております。

{{制作物}}が完成いたしましたので、納品させていただきます。

## 納品物

- {{ファイル1}}: {{説明}}
- {{ファイル2}}: {{説明}}
- {{手順書}}: {{説明}}

## インストール手順

{{手順書}}に記載しておりますが、
簡単な手順は以下の通りです。

1. {{手順1}}
2. {{手順2}}
3. {{手順3}}

## 公開前のご確認

以下の点について、公開前にご確認いただけますでしょうか。

- [ ] {{確認項目1}}
- [ ] {{確認項目2}}
- [ ] {{確認項目3}}

確認が取れ次第、本番反映のご案内をさせていただきます。

よろしくお願いいたします。
```

### 4.2 インストールガイド送付

**使う場面**: WordPressテーマ等、インストール手順を説明するとき

```
件名: インストール手順書のご送付

{{クライアント名}} 様

お世話になっております。

{{テーマ名}}のインストール手順について、
詳細をまとめた手順書をお送りいたします。

## インストール方法

### 方法1: 管理画面からアップロード（推奨）

1. {{テーマフォルダ}}をzip圧縮
2. WordPress管理画面 > 外装 > テーマ > 新規追加
3. 「テーマのアップロード」をクリック
4. zipファイルを選択して「今すぐインストール」
5. 「有効化」をクリック

### 方法2: FTP/SFTPでアップロード

1. サーバーへ接続
2. `/wp-content/themes/{{テーマ名}}/` へアップロード
3. 管理画面からテーマを有効化

## 設定項目

### {{設定A}}

{{設定手順}}

### {{設定B}}

{{設定手順}}

## トラブルシューティング

### Q. {{問題A}}
A. {{解決策}}

### Q. {{問題B}}
A. {{解決策}}

不明点がございましたら、お気軽にお問い合わせください。

よろしくお願いいたします。
```

## 5. トラブル対応

### 5.1 不具合報告受領

**使う場面**: クライアントから不具合報告を受けたとき

```
件名: Re: {{件名}}

{{クライアント名}} 様

お世話になっております。

ご報告いただいた不具合について確認いたしました。

## 確認事項

- {{不具合内容}}
- 発生環境: {{環境情報}}
- 発生頻度: {{頻度}}

## 対応方針

{{対応内容}}

## 見積もり

- 修正工数: {{工数}}
- 対応予定: {{日程}}

至急、対応させていただきます。

ご不便をおかけいたしますが、今しばらくお待ちください。

よろしくお願いいたします。
```

### 5.2 緊急時対応

**使う場面**: 緊急で対応が必要なとき

```
件名: 【重要】{{件名}}に関する緊急対応

{{クライアント名}} 様

お世話になっております。

{{問題}}につきまして、緊急対応を実施いたします。

## 状況
{{現在の状況}}

## 即時対応
{{実施した対応}}

## 今後の予定
{{今後の対応}}

引き続き、状況をご報告させていただきます。

何卒よろしくお願いいたします。
```

## テンプレート使用上の注意

1. **文脈に合わせて調整する**: テンプレートはあくまで参考
2. **クライアントの言葉遣いに合わせる**: 丁寧すぎず、親身すぎず
3. **選択肢を提示する**: 複数の案から選んでもらう形式が円滑
4. **期待値管理をする**: できること・できないことを明確に
5. **次のアクションを明示する**: 「何を」「いつまでに」依頼するか
