# client_messages

## 目的
- クライアントから受信した文面を時系列で一元管理する。
- `client/` にある送付文面と対応関係を追えるようにする。
- コミュニケーションパターンのテンプレート化と資産化。

## ルール
- 受信文面の正本はこのディレクトリに置く。
- ファイル名は `CLIENT_MESSAGE_XXX_*.md` 形式で連番管理する。
- 一覧管理は `CLIENT_MESSAGE_INDEX.md` を更新する。
- 送付文面は `../client/` に置き、受信文面と混在させない。

## ファイル構成

### 受信文面管理
- `CLIENT_MESSAGE_INDEX.md` - 受信文面の一覧（対応状況の管理）
- `CLIENT_MESSAGE_XXX_*.md` - 個別の受信文面

### テンプレート集（送信文面の参考）
- `MESSAGE_TEMPLATE_COLLECTION.md` - シーン別のメッセージテンプレート集
  - 初期フェーズ・制作フェーズ・レビューフェーズ・公開フェーズ・トラブル対応
- `RESPONSE_PATTERN_GUIDE.md` - クライアントの質問に対する回答パターン集
  - 選択肢提示・フィードバック対応・タイムライン調整・不具合対応・スコープ調整・決定促進

## テンプレートの使い方
1. 該当するシーンのテンプレートを見つける
2. {{変数}} を案件固有の情報に置き換える
3. クライアントの性格・関係性に合わせてトーンを調整する
4. 必ず文脈に合わせてカスタマイズしてから送信する
