## インストール手順

### 方法1: 管理画面からアップロード（推奨）

1. **テーマファイルの準備**
   - `{{テーマディレクトリ名}}` フォルダを zip 圧縮

2. **WordPress管理画面へアクセス**
   - `外装` > `テーマ` > `新規追加`

3. **テーマのアップロード**
   - 「テーマのアップロード」ボタンをクリック
   - zipファイルを選択して「今すぐインストール」

4. **テーマの有効化**
   - インストール完了後、「有効化」をクリック

5. **表示確認**
   - サイトを表示してLPを確認

---

### 方法2: FTP/SFTPでアップロード

1. **サーバーへ接続**
   - FTP/SFTPクライアントでサーバーへ接続

2. **テーマディレクトリへアップロード**
   ```
   /wp-content/themes/{{テーマディレクトリ名}}/
   ```
   上記パスへファイルをアップロード

3. **テーマを有効化**
   - WordPress管理画面 > 外装 > テーマ
   - 「{{テーマ名}}」を有効化

## 設定項目

### Contact Form 7 の連携

**functions.php** の以下の箇所を設定してください：

```php
// Contact Form 7 のフォームIDを指定
$form_id = 0; // ← 実際のフォームIDに変更してください
```

1. Contact Form 7でお問い合わせフォームを作成
2. フォームの投稿IDを確認（管理画面「お問い合わせ」からフォーム編集画面のURLを確認）
3. `$form_id` を実際のIDに書き換え

### OGP設定

**functions.php** の以下の箇所を本番環境に合わせて調整してください：

```php
// OGP用画像（現在は外部画像を使用）
$image = 'https://images.unsplash.com/...';

// 必要に応じて自社のOGP用画像URLに変更してください
$image = 'https://your-domain.com/path/to/og-image.png';
```

本番環境のURLやOGP用画像を準備されている場合は、functions.phpの`$image`変数を差し替えをお願いします。

## カスタマイズについて

本テーマは静的LPをWordPressテーマ化したものです。
デザインやテキストの変更は以下のファイルで行います：

- **デザイン・レイアウト**: `style.css`
- **LPコンテンツ**: `index.php`
- **ヘッダー**: `header.php`
- **フッター**: `footer.php`
- **スクリプト**: `js/script.js`

## 動作環境

- WordPress 5.0以上
- PHP 7.4以上推奨
- Contact Form 5.0以上（お問い合わせ機能を使用する場合）

## 注意事項

1. **子テーマについて**
   - 本テーマは単体LP用のため、子テーマ作成は不要です

2. **アップデートについて**
   - テーマのアップデート機能はありません
   - 修正が必要な場合は直接ファイルを編集してください

3. **バックアップ**
   - アップロード前に既存サイトのバックアップをお願いします
