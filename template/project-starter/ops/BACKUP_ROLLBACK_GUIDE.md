## ロールバック手順

### 前提

本案件での作業内容に応じたロールバック方法を記載します：

1. **テーマの無効化**: 「{{テーマ名}}」を無効化 → 元のテーマに戻す
2. **テーマの削除**: テーマを削除して元の状態に戻す
3. **サーバーバックアップ**: ホスト側のバックアップから復元（最終手段）

### ロールバック手順

#### 方法1: テーマの無効化（推奨・最速）

1. WordPress管理画面にログイン
2. 「外装」>「テーマ」をクリック
3. 「{{テーマ名}}」の「詳細を表示」をクリック
4. 「無効化」をクリック
5. 元のテーマを有効化

**復旧時間**: 1分以内

#### 方法2: テーマの削除

1. WordPress管理画面にログイン
2. 「外装」>「テーマ」をクリック
3. 「{{テーマ名}}」の「詳細を表示」をクリック
4. 「削除」をクリック

**復旧時間**: 1分以内

#### 方法3: サーバーバックアップ（緊急時）

**ホスト側のバックアップが利用可能か、事前に確認が必要です。**
