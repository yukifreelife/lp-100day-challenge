# LPオートメーション計画 v2

**Date**: 2026-04-16
**Status**: 設計完了

---

## 方向性

LP制作を以下の3段階で自動化・標準化する：

1. **汎用作成スキル** - すべてのLPに適用される基盤
2. **業種別設定スキル** - カテゴリー特化のデザイン・構成
3. **評価スキル** - 閾値4.0以上を担保する品質チェック

---

## スキル構成

### 1. 汎用作成スキル（全LP共通）

**目的**: すべてのLPで担保すべき基盤を提供

| 領域 | 内容 |
|------|------|
| HTML構造 | セマンティック、正しい見出し階層 |
| CSS | CSS変数、レスポンシブ、ブレークポイント |
| JavaScript | スムーズスクロール、モバイルメニュー、フォーム処理 |
| アクセシビリティ | :focus-visible、スキップリンク、コントラスト比、ARIA |
| セキュリティ | textContent使用、XSS対策、入力バリデーション |
| 法務コンプライアンス | 特商法表記枠、プライバシーポリシー枠 |
| パフォーマンス | lazy loading、画像最適化、Core Web Vitals配慮 |
| アナリティクス | GA4枠、CVトラッキング枠 |
| SEO | metaタグ、構造化データ、h1×1 |

**出力**: index.html, css/style.css, js/script.js の骨格

---

### 2. 業種別設定スキル（カテゴリー別）

**目的**: 業種の特性に合わせたデザイン・言語・構成を提供

| カテゴリー | 色 | フォント | 特有要素 |
|-----------|-----|----------|----------|
| 飲食店 | 暖色/和色 | 寝ざらかし/明朝 | O2O、予約、ギャラリー |
| 医療 | 青/緑/白 | 游ゴシック/メディアム | 資格、診療時間、症例 |
| B2B/SaaS | コーポレート | Noto Sans/Inter | 価格、導入事例、CTA強化 |
| 不動産 | 高級感/ベージュ | 明朝/ヒラギノ | 間取り、周辺地図、VR |
| 教育 | 親しみ | ゴシック/丸ゴ | カリキュラム、講師、体験 |
| 採用 | ブランド色 | 各社フォント | 文化、福利厚生、先輩 |

**出力**: カラーパレット、フォント設定、セクション構成案

---

### 3. 評価スキル

**目的**: LPの品質を10〜13領域で評価、閾値4.0以上を担保

| 評価項目 | 汎用 | 業種別 |
|----------|------|--------|
| デザイン & ビジュアル | ○ | - |
| UX & 情報設計 | ○ | - |
| コーディング品質 | ○ | - |
| コンテンツ戦略 | ○ | - |
| コンバージョン最適化 | ○ | - |
| SEO | ○ | - |
| ブランド戦略 | ○ | - |
| 心理学・行動デザイン | ○ | - |
| アクセシビリティ | ○ | - |
| セキュリティ | ○ | - |
| アナリティクス | ○ | - |
| 法務コンプライアンス | ○ | - |
| パフォーマンス | ○ | - |
| O2O | - | △（業種による） |

**閾値**: 平均スコア 4.0 / 5.0 以上で合格

---

## フロー

```
1. ユーザー入力
   ↓
2. 業種別スキル起動 → 色・フォント・構成決定
   ↓
3. 汎用作成スキル起動 → HTML/CSS/JS生成
   ↓
4. 画像取得（Unsplash/Pexels）
   ↓
5. 評価スキル起動
   ↓
6. スコア < 4.0 ?
   ├→ Yes: 自動改善 → 再評価
   └→ No: 完了
```
