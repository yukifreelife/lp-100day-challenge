## パフォーマンス最適化チェックリスト

### Lazy Loading
- [ ] ヒーロー画像に `loading="eager"` を指定
- [ ] その他の画像に `loading="lazy"` を指定
- [ ] iframeに `loading="lazy"` を指定（該当場合）
- [ ] width/height属性を全画像に指定
- [ ] Intersection Observerポリフィルを実装（オプション）

### Core Web Vitals - LCP
- [ ] ヒーロー画像を preload
- [ ] フォントを preconnect
- [ ] Webフォントに `display=swap` を指定
- [ ] レスポンシブ画像（srcset）を実装
- [ ] 第一フォールドのCSSをインライン化

### Core Web Vitals - FID/INP
- [ ] JavaScriptを defer で読み込み
- [ ] 長時間実行タスクを分割（該当場合）
- [ ] 第三者スクリプトを非同期化

### Core Web Vitals - CLS
- [ ] 画像に aspect-ratio を指定
- [ ] 広告枠に min-height を指定（該当場合）
- [ ] 動的コンテンツ用スペースを確保
- [ ] フォント用の予約スペースを確保
