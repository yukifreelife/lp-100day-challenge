### 対象となる悩み・相談先

```
見出し（h2）：よくある相談内容

本文：
採用専任者がいない中小製造業で、以下のようなお悩みをお持ちではありませんか。

・求人を出しても応募が来にくい状態が続いている
・応募があっても、会社見学や次の接点につながりにくい
・仕事内容や職場の雰囲気がうまく伝わっていない感覚がある
・採用側でも、何を優先して見直すべきか整理しきれていない
・発信したい気持ちはあるが、何を出すべきか整理できていない
・会社の雰囲気や働く人の様子が十分に伝わっていない

こうした課題は、求人原稿だけでは完結しないことが多いです。
仕事内容の伝え方、見学導線、発信内容、受け皿ページなどが分散しているケースが多く、どこから手を付けてよいか分からなくなることも少なくありません。

ミチル採用企画では、まず現状を整理することから支援を始めます。
いきなり大きな施策を提案するのではなく、今ある採用活動を前提に、何を先に見直すべきかを一緒に整理します。
```

### サポート内容

```
見出し（h2）：相談で整理できること

本文：
製造業の採用課題は、会社ごとに状況が異なります。
そのため、テンプレートの施策提案ではなく、まず現状整理から入る進め方をとっています。

主に整理できるのは、以下のようなポイントです。

・求人原稿の訴求整理
・会社見学までの案内導線の見直し
・応募者へ伝える内容の優先順位整理
・現場の雰囲気をどう見せるかの整理
・採用向け発信の方向性整理
・採用ページとの役割分担の整理

まずは初回相談で、現在の状況と課題についてお聞かせください。
その中で、何から優先して見直すべきか、どの情報をどこで見せるべきかを一緒に整理していきます。
```

### 運営者プロフィール

```
見出し（h2）：ごあいさつ

本文：
ミチル採用企画と申します。
愛知県を拠点に、中小製造業向けの採用広報支援を行っています。

【よくお問い合わせいただく方】
・採用専任者がいない会社の経営者様
・採用業務を兼任されている総務担当者様
・応募が来ない以前に、何から整えるべきか分からないと感じている会社様
・発信や見学導線など、複数の箇所を同時に見直したいと考えている会社様

こうした会社様から、
「求人原稿だけでなく、全体の採用導線を見てほしい」
「採用専任がいない現実を踏まえて、現実的に進めたい」
「まずは状況を整理して、優先順位を見つけたい」
といったご相談を多くお伺いしています。

【大事にしている考え方】
製造業の採用課題は、求人票だけで完結しないことが多いです。
仕事内容の伝え方、見学導線、発信内容、受け皿ページなどが分散しているケースが多く、どこから手を付けてよいか分からなくなることも少なくありません。

そのため、いきなり施策を増やすより、まず現状整理と優先順位整理を重要と考えています。
採用専任者がいない会社でも進めやすい形で支援することを大事にしています。

初回相談は、専門用語で説明するのではなく、お話を伺いながら状況を一緒に整理する時間を想定しています。
製造業の実情を踏まえて、現実的に見ていける範囲でご相談をお伺いします。
```

### 相談後の流れ

```
見出し（h2）：初回相談の流れ

本文：
フォーム送信後、すぐに提案や見積りが出るわけではありません。

まずはオンラインで30〜45分程度、状況整理の時間としてご相談いただけます。

初回相談の中で、現在の採用活動と課題についてお聞かせいただき、何を優先して見直すべきかを一緒に整理していきます。

その後、必要があれば個別提案という形で進めます。

相談したら必ず契約になるわけではありません。
まずは現状整理の時間としてご相談いただけます。
```
