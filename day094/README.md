## 実装用素材

- `assets/icons/*.svg` - HTML/CSSで再利用しやすい線画SVGアイコン
- `design/tokens.css` - カラーパレットと基本UIトークン
- `design/tone-and-manner.md` - トンマナの要点
- `assets/asset-manifest.json` - 素材の用途一覧

## UI方針

白基調、ティールCTA、ミントの補助面、控えめな黄色アクセントで、信頼感と親しみやすさを両立する。
