# NemuNote Day094

Minimal Vite React scaffold for the NemuNote landing page.

## Setup

```bash
npm install
npm run dev
```

## Files Owned By Worker A

- `package.json`
- `index.html`
- `vite.config.js`
- `README.md`

## Notes

- Tailwind CSS is loaded from the CDN in `index.html` so the scaffold can stay small.
- React source files under `src/` are intentionally left untouched for the owning worker.
- The Vite entry is expected at `src/main.jsx`.
