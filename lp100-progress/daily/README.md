# 日次ログ

## 役割
- `day001.md` から `day049.md` までの作業ログ正本を保持する。
- 各ファイルには、その日の成果、作業時間、詰まり、学び、次回やることを残す。

## 命名ルール
- 形式は `dayXXX.md`
- 新しい日を追加するときは、`../templates/DAILY_PROGRESS_TEMPLATE.md` を複製して使う。

## 収録範囲
- `day001.md` 〜 `day014.md`
  - テンプレ差し替えと基礎制作期
- `day015.md` 〜 `day023.md`
  - 税務・節税相談LPの仮案件期
- `day024.md` 〜 `day030.md`
  - 新規LP設計と実装拡張期
- `day031.md` 〜 `day049.md`
  - 実案件想定の制作、公開、改善、計測レビュー期
