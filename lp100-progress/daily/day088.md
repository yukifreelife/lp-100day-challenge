## 次回の方向性: SPAとしてLPを作成

### 現在のLP構造との違い
| 項目 | 現在（静的LP） | 次回（SPA） |
|------|----------------|------------|
| ページ遷移 | なし（スクロール） | JSで動的切り替え |
| ルーティング | アンカーリンク | History API / hash |
| データ取得 | なし | API通信 |
| コンテンツ | 静的HTML | 動的レンダリング |
| フレームワーク | なし | React / Vue / Next.js |

### SPA採用の理由
1. **動的コンテンツ切り替え**: ユーザー操作に応じたコンテンツ表示
2. **スムーズな遷移**: ページリロードなしのUX
3. **状態管理**: フォーム入力、選択内容の保持
4. **API連携**: 将来的な拡張性

### 採用予定の技術スタック
- **Framework**: Next.js（Reactベース）
- **Hosting**: Cloudflare Workers
- **Routing**: App Router（Next.js 13+）
- **State**: React Context / Zustand
- **Styling**: Tailwind CSS

### SPA LPで実装したい機能
1. **ルーティング**: /story, /lineup, /process などのパス
2. **アニメーション**: ページ遷移アニメーション（Framer Motion）
3. **プリフェッチ**: リンクホバー時のデータ先読み
4. **フォーム**: マルチステップフォーム
5. **カート機能**: 商品選択→購入フロー

### 課題
- Cloudflare WorkersでのNext.jsホスティング設定
- SSG/SSRの使い分け
- 画像最適化（next/image）
- APIルートの実装
