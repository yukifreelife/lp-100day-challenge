# LP100 Progress Hub

## 目的
- LP-100チャレンジの進捗記録を、案件ディレクトリから分離して一元管理する。
- 日ごとの作業時間、成果、学び、次回課題をここで追い、`dayXXX/` 側は制作物と案件運用ファイルに寄せる。

## このフォルダに置くもの
- `daily/`
  - 各日の進捗ログ正本。ファイル名は `dayXXX.md` で統一する。
- `reviews/`
  - 月次・期間レビュー、総括、振り返り。
- `skills/`
  - スキル棚卸し、優先順位表、学習ロードマップ。
- `templates/`
  - 今後の進捗記録テンプレ。
- `archive/`
  - 過去版ログや差し替え前の記録。

## このフォルダに置かないもの
- LP本体、画像、HTML/CSS/JS、納品物
- 仮案件の要件定義、クライアント返信、公開運用メモ
- WordPress反映手順や計測運用など、案件固有の実務資料

## 今後の運用ルール
1. 新しい `dayXXX/` を始めたら、進捗ログは `lp100-progress/templates/DAILY_PROGRESS_TEMPLATE.md` を元に `lp100-progress/daily/dayXXX.md` を作る。
2. `dayXXX/` 側には、実装正本・案件資料・補助ファイルのみを置く。
3. 日次の成果や作業時間を見返すときは、まず `daily/` を起点にする。
4. 週次・月次の振り返りは `reviews/`、スキル整理は `skills/` に追記する。
