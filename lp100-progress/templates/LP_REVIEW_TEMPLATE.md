## 各領域の評価基準

### 領域1: デザイン & ビジュアル

**評価項目:**
- [ ] カラースキームの一貫性（ブランドカラーの使用比率）
- [ ] タイポグラフィの階層性（h1, h2, h3, bodyの関係性）
- [ ] レイアウトのバランス（余白、グリッド、アライメント）
- [ ] 視線誘導（Fパターン、Zパターンへの適合）
- [ ] ビジュアル hierarchy（サイズ、色、配置で優先順位を表現）

**評価基準:**
| ランク | 基準 |
|-------|------|
| S | プロフェッショナルレベル、競合と明確な差別化あり |
| A | 実用レベル十分、支障はない |
| B | 一部改善余地あり |
| C | 重大な問題あり |
| D | 修正必須 |

## レビュープロセス

### ステップ1: 事前確認
1. LPの目的、ターゲット、KPIを確認
2. 競合LPを3件程度リサーチ
3. ペルソナ（ターゲットユーザー）を確認

### ステップ2: コードレビュー
1. HTML/CSS/JSを読み込み
2. 各領域の評価基準に照らしてチェック
3. 具体的な改善案を記録

### ステップ3: ブラウザレビュー
1. http://localhost:8080/ で表示確認
2. レスポンシブ（PC/タブレット/スマホ）で確認
3. スクロールアニメーション、ホバー効果を確認
4. フォーム操作、タブ切り替えなどを確認

### ステップ4: 総合評価
1. 各領域の評価を集計
2. 優先度マトリックスを作成
3. クライアントと合意を形成

### ステップ5: フィードバック
1. 具体的な改善案を提示
2. 実装コードを提示（必要に応じて）
3. 優先順位を提案

## クイックチェックリスト

### 必須チェック（これだけは見る）

```markdown
## ファーストビュー（FV）
- [ ] キャッチコピーは独自性があるか
- [ ] CTAボタンが見えているか
- [ ] 社会的証明が表示されているか
- [ ] 何を提供しているかが1秒でわかるか

## CTA
- [ ] CTAボタンは複数箇所にあるか（FV、中盤、最後）
- [ ] CTAの文言は具体的か（「詳細」→「無料体験を予約」）
- [ ] CTAの色は目立っているか

## 信頼性
- [ ] 実績（数字）があるか
- [ ] お客様の声があるか
- [ ] 資格・認証があるか
- [ ] 会社情報（住所、電話）があるか

## 不安解消
- [ ] FAQがあるか
- [ ] 保証・返金ポリシーがあるか
- [ ] 料金が明記されているか
- [ ] キャンセル条件があるか

## モバイル
- [ ] スマホで見やすいか
- [ ] CTAボタンは押しやすいサイズか
- [ ] フォームは入力しやすいか
- [ ] 読み込み速度は問題ないか

## SEO
- [ ] Titleタグがあるか（30文字以内）
- [ ] meta descriptionがあるか
- [ ] h1タグは1つか
- [ ] 画像にalt属性があるか
```

## テンプレート使用方法

1. LPレビュー時にこのテンプレートを開く
2. 10領域の評価基準に照らしてチェック
3. 各領域のレビュー記述テンプレートを使用して記述
4. 総合評価マトリックスを作成
5. 改善提案を実装コード付きで提示
