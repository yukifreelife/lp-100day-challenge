## 5. 改善推奨（優先順位順）

### 🔴 緊急（SEO・信頼性への影響大）

1. **OGP画像の実装**
   - 現状: `ogp.jpg`（プレースホルダー）
   - 対策: 1200x630pxのOGP画像を作成

2. **description の拡充**
   - 現状: 45文字
   - 目標: 120文字前後
   - 例: 「無農薬・無化学肥料で育てた有機JAS認定の野菜を、収穫から24時間以内にご自宅までお届けする定期宅配サービスです。25年間無農薬栽培を実践し、1,200世帯様にご愛用いただいています。」

3. **法務ページのプレースホルダー整備**
   - プライバシーポリシー
   - 特定商取引法に基づく表記

### 🟡 重要（ユーザー体験向上）

4. **JSON-LD構造化データの追加**
   ```html
   <script type="application/ld+json">
   {
     "@context": "https://schema.org",
     "@type": "LocalBusiness",
     "name": "アース・ナチュラル・グリーン",
     "description": "無農薬・無化学肥料の有機野菜定期宅配サービス"
   }
   </script>
   ```

5. **お客様の声セクションの追加**
   - 現状: 信頼性数字のみ
   - 改善: 口コミやお客様の声を追加

6. **画像alt属性の改善**
   - broccoli.png: 「無農薬栽培」→「ブロッコリーの無農薬栽培」
   - komatsuna.png: 「新鮮配送」→「新鮮な小松菜」
   - zucchini.png: 「安心安全」→「ズッキーニ」

### 🟢 改善（品質向上）

7. **画像にwidth/height属性を追加**
   - CL S（Cumulative Layout Shift）対策

8. **titleタグの拡張**
   - 現状: 22文字
   - 目標: 30文字前後
   - 例: 「有機野菜の定期宅配｜アース・ナチュラル・グリーン｜無農薬栽培」
