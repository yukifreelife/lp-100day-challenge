# 商材 / サービス概要
今回LP化したい商材は、秋山本人のサービスではなく、**秋山が自社集客のために売りたい主力サービス**。

- **商材名**：製造業向け採用導線診断＆会社見学導線設計パック
- **提供形態**：
  - 初回オンライン相談 60分
  - 現状ヒアリング
  - 採用導線の簡易診断
  - 会社見学の設計アドバイス
  - 必要に応じて継続支援提案
- **販売形態**：
  - まずはLPから無料相談予約
  - その後オンライン面談
  - そこで単発診断または継続伴走を提案
- **価格**
  - LP上では「無料相談」
  - 本契約は単発5万円前後 / 継続10万円前後から
- **対象**：
  - 製造業の経営者・工場長・採用兼務の総務担当
- **ユーザーの悩み**：
  - 求人媒体に出しても応募が少ない
  - 若手が来ない
  - 見学は来ても応募につながらない
  - 自社の魅力が言語化できない
  - 現場の雰囲気が伝わらない

# 案件背景
- **なぜ今LPを作りたい / 改善したいのか**
  - これまで紹介と既存人脈中心で受注してきたが、紹介だけでは売上が不安定
  - 今年からMeta広告やInstagram導線を使って新規獲得を強めたい
  - 既存サイトはあるが、サービス内容が散らばっていて相談につながりにくい
- **きっかけ**
  - 2か月前に広告運用者から「まず受け皿LPが弱い」と言われた
  - 以前作ったサイトから問い合わせは月1〜2件程度
  - 相談に来ても「何をしてくれる人か分からなかった」と言われた
- **表面上困っていること**
  - LPがない / 弱い
  - 見た目が古い
  - 予約につながらない
  - どこを改善すればいいか分からない
- **本質課題として疑わしいこと**
  - 流入の訴求とLP訴求がずれている
  - 「無料相談」で来るが、商談化しにくい
  - 面談時の提案内容が属人的で再現性が低い
  - 価格の伝え方が弱く、継続支援の納得感が不足
  - そもそもターゲットが広く、刺さる相手がぼやけている
- **過去に何があったか**
  - 知人デザイナーにサイトを作ってもらったが、見た目重視で集客導線は薄かった
  - 広告運用者からは「LPと計測を整えないと最適化しづらい」と言われた
  - 別のコンサルには「無料相談より資料請求の方が良い」と言われ、方針が揺れている
- **不信感 / 焦り / 期待**
  - 不信感：以前、制作後に「修正は別料金」と多く言われて不満が残った
  - 焦り：今期中に安定した新規流入の型を作りたい
  - 期待：デザインを良くすれば反応が上がるのではと思っている
  - ただし薄く「自分の説明の仕方にも問題あるかも」と感じている

# 訴求と証拠の現状
## いま打ち出している強み
- 製造業採用の現場感がある
- 求人広告営業経験がある
- 現場に合う言葉で整理できる
- 会社見学導線まで見られる
- 大手コンサルほど高くない

## 差別化の弱さ / 強さ
- **強さ**：
  - 製造業特化は一定の説得力あり
  - 現場理解が浅いデザイナー系より信頼は取りやすい
- **弱さ**：
  - 「採用コンサル」「採用広報支援」「SNS支援」と表現が散っている
  - 他社との決定的な違いが一文で言えない
  - 成果保証があるわけではない

## 実績・証拠素材
- 企業名を出せない案件が多い
- 一部、匿名なら紹介可
- before/afterの定量実績は弱い
- お客様の声はLINE文面や口頭感想レベル
- 写真はあるが整理されていない
- セミナー登壇実績はある

## 顔出し / プロフィール / 世界観
- 顔出し可
- 本人写真あり
- 世界観は「泥臭く現場に寄り添う」方向
- ただしデザイン表現としては未整理

## 高単価納得材料
- 製造業採用に絞った支援経験
- 実務経験
- 現場改善視点
- ただし、体系化されたメソッド図や比較表は未整備

## クライアントが思う強み
- 「製造業のことが分かる」
- 「ふわっとしたブランディングではなく現実的」
- 「話しやすい」

## ユーザーから見た本当の魅力 / 不安
- **魅力**
  - 現場理解がありそう
  - 大手より相談しやすそう
  - 会社見学や応募導線まで見てくれそう
- **不安**
  - 実績はどれくらいあるのか
  - 本当に応募が増えるのか
  - SNS運用屋なのか採用設計屋なのか分かりにくい
  - 無料相談後にどんな提案が来るのか見えない

## 曖昧な点
- 誰に最も効かせるべきかが曖昧  
  （経営者向けか、採用兼務担当向けか）
- どの不安に一番効かせるかが曖昧  
  （応募不足か、見学後離脱か、発信不足か）
- どの証拠で押し切るかが曖昧  
  （実績数か、経験か、現場理解か、工程理解か）

# ロールプレイ時の注意点
- 今後私はこのクライアント「秋山美穂」として振る舞う
- 最初から全部は出さない
- ただし聞かれたことには自然に答える
- 曖昧な部分は「たぶん」「確認します」「前の人が触っていて…」など自然に返す
- LP外課題を指摘されたら、最初は少し驚く
  - 例：「え、そこってLPだけの話じゃないんですね」
- スコープを切られたら少し戸惑う
  - 例：「そこまで別なんですね、どこまで含まれるイメージですか？」
- 予算は抑えたいが、成果期待は高め
- 協力はするが、素材整理・数値整理は弱い
- 急に
  - 「LINE導線も入れたい」
  - 「やっぱり資料DLも欲しい」
  - 「広告の人がCTA変えたいと言っていて」  
  のような追加要望が出る余地がある
- 制作者が確認しなければ、
  - 本番受信先
  - 権限
  - 法務表記
  - 計測所有権
  - 実績利用許可  
  が後から問題化する
