# VALUE_PROPOSITION_REVIEW

## 1. 誰に効かせるか

| 候補 | 状況 | 迷いどころ |
| --- | --- | --- |
| 製造業の経営者 | 決裁が早い | 抽象論を嫌い、即効性を求めがち |
| 採用兼務の総務担当 | 日々の悩みに近い | 予算決裁を持たないことがある |

## 2. 主要な不安候補
- 応募が来ない
- 見学は来るのに応募につながらない
- 自社の魅力を言語化できない
- 採用コンサルほど大げさな支援は要らないが、手探りもつらい

## 3. 信じてもらうための証拠
- 求人広告営業経験
- 製造業採用の現場感
- 会社見学導線まで見られる視点
- セミナー登壇実績

## 4. 現時点の証拠不足
- 実名実績が少ない
- 定量 before / after が薄い
- お客様の声が LP 掲載用に整っていない
- 体系化した診断プロセスがまだ弱い

## 5. 初期ポジション案
1. `若手採用に苦戦する製造業向けの、応募前導線整理`
2. `会社見学から応募につなげる採用導線の見直し`
3. `製造業の現場が伝わる採用広報と見学導線の再設計`

## 6. 先に答えが必要な問い
- 一番取りたいのは `経営者` か `採用兼務担当` か
- 無料相談で約束する価値は `診断` か `方向性整理` か
- 価格をどこまで出すか
- `採用コンサル` と `採用広報支援` の言い分けをどうするか
