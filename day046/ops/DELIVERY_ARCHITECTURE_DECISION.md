## 実装候補

| 案 | 概要 | 利点 | リスク | 先に確認すべきこと |
| --- | --- | --- | --- | --- |
| A | 既存 WordPress 固定ページ + カスタム HTML | 既存サイト内で公開しやすい | テーマ制約で再現性が落ちる | HTML / CSS / JS の挿入可否 |
| B | 別 LP を静的で作り、WP からリンク | 表現自由度が高い | クライアント自己修正性が落ちる | サーバー設置場所、更新導線 |
| C | WordPress ビルダー上で構築 | 自己修正しやすい | LP 的な細かい制御が弱い | 使用ビルダー、実装自由度 |

## 必須確認項目
- HTML はどこへ入れるか
- CSS はどこへ入れるか
- JS はどこへ入れるか
- フォームは既存プラグイン流用か、新設か
- 予約はフォーム送信後の手動調整か、予約ツール導入か
- 計測タグは誰がどの権限で管理するか
