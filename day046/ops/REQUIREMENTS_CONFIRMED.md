# REQUIREMENTS_CONFIRMED

> 受注前の仮確定版。クライアントヒアリング後に `確定` と `保留` を更新する。

## 仮確定している要件
- LPの主目的は `無料相談予約`
- 対象は `地方製造業の経営者 / 工場長 / 採用兼務担当`
- 既存 WordPress サイト内で運用したい希望がある
- スマホで読みやすいことが必須
- 製造業特化であることが一目で分かる訴求が必要
- クライアント自身が文言や画像を後から修正できる安心感を重視している
- 広告導線の受け皿として使う想定がある
- 大企業っぽい冷たい印象、キラキラしすぎるデザイン、成果保証っぽい表現は避ける

## まだ確定していない要件
- 予約導線を `問い合わせフォーム / LINE / 予約ツール` のどれに寄せるか
- 副CV を初回制作にどこまで含めるか
- 価格情報を LP 上でどこまで出すか
- 計測の対象を `CTAクリック / フォーム送信 / 予約完了` のどこまでにするか
- WordPress の実装方式と編集可能範囲
- 軽微修正の回数または期間

## 初回制作に含めない前提候補
- 広告運用の最適化
- 面談設計の全面改善
- 提案書テンプレートの整備
- 長期の分析伴走
- 資料DL 導線の新規制作

## リスクメモ
- `LPが弱い` という相談だが、本質課題は面談後の提案設計かもしれない
- 実績の匿名制約により、証拠の出し方を工夫する必要がある
- 計測アカウントの所有権が曖昧なままだと公開後に詰まる
