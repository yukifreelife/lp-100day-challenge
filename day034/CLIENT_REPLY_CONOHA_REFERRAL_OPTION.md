# Day034 ConoHa紹介制度 案内文テンプレ

作成日: 2026-02-28
用途: クライアントへ「ConoHa WINGのお客様紹介プログラム」を使う案内を送るための文面

## クライアント送信用（そのまま使える文面）

```text
件名: ConoHa WINGお申込みのご案内（ご紹介制度のご利用について）

お世話になっております。
ConoHa WINGのお申込みについて、初回費用を少し抑えられる可能性がある方法がありますのでご案内いたします。

ConoHaの「お客様紹介プログラム」を使ってお申込みいただくと、
条件を満たした場合、初回お支払い時に割引が適用されることがあります。

今回の進め方では、以下の条件に当てはまれば対象になる可能性が高いです。

【割引対象になりやすい条件】
1. 紹介用URLからお申込みする
2. 新しくConoHaアカウントを作成してお申込みする
3. ConoHa WINGの「WINGパック」で、12か月以上を選ぶ

ご利用いただく場合は、下記のURLからアクセスをお願いいたします。
[紹介URLをここに記載]

【ご注意】
- すでにConoHaアカウントをお持ちの場合は、対象外になる可能性があります。
- 紹介用URLには有効期限がありますので、URL受け取り後はできるだけ早めのお申込みをお願いします。
- 最終的な割引適用は、ConoHa側の申込画面・決済画面の表示をご確認ください。
- 他のキャンペーンとの組み合わせは、申込時の表示を優先して確認してください。

お手数ですが、上記URLからそのままお申込みを進めていただけますと幸いです。

ご不明点があれば、途中画面のスクリーンショットをお送りください。
次に押す箇所をこちらでご案内いたします。
引き続きよろしくお願いいたします。
```

## こちらの運用メモ
- 先に「クライアントが未登録のConoHaアカウントか」を確認する。
- 紹介URLの有効期限は6日なので、送ったら放置しない。
- 割引の適用有無は、クライアントに申込画面のスクリーンショットを送ってもらって確認する。
- 割引を断定しない。「適用されることがあります」「対象になる可能性があります」の表現を維持する。
- こちらが `パートナープログラム` や `アフィリエイト` を使う場合は、制度の併用可否を先に整理してから案内する。
