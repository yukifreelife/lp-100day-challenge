# Day034 WordPress管理画面 操作手順

作成日: 2026-02-28  
目的: ログイン後に迷わず移行を進めるための操作順

## 1. 固定ページの確認
1. 管理画面にログイン
2. 左メニューの `固定ページ`
3. `WP固定ページ納品用` を探す
4. 使う場合は `編集`
5. 使わない場合は `新規固定ページを追加`

### この段階で決めること
- 既存ページを使うか
- 新規ページを作るか

## 2. メディアのアップロード
1. 左メニューの `メディア`
2. `新しいメディアファイルを追加`
3. 画像一式をアップロード
4. 続けて `food-checklist.pdf` をアップロード
5. 各ファイルのURLを控える

### 最低限控えるもの
- ヒーロー画像URL
- 理由セクションの3系統の画像URL
- 背景画像URL
- PDF URL

## 3. 法務ページの作成
1. 左メニューの `固定ページ`
2. `新規固定ページを追加`
3. `プライバシーポリシー` を作成
4. `特定商取引法` を作成
5. 公開後、それぞれのURLを控える

## 4. トップLP本文の投入
1. トップLPに使う固定ページを開く
2. ブロックエディタの場合は `カスタムHTML` ブロックを使う
3. `day034/source/index.html` の本文をベースに貼り付ける
4. 画像・PDF・法務リンクを WordPress のURLへ差し替える
5. 一度 `下書き保存` または `更新`

## 5. CSSの適用
1. `外観`
2. `カスタマイズ`
3. `追加CSS`
4. `day034/source/styles.css` の内容を貼り付け
5. 相対パスが残っていないか確認
6. `公開`

## 6. JSと設定値の適用
実装方法はどちらかで進める。

### 方法A: コード挿入プラグインあり
1. ヘッダーに `day034/LP_CONFIG_SNIPPET.html`
2. フッターに `day034/source/script.js`

### 方法B: 固定ページ内で対応
1. ページ上部の HTML ブロックに `day034/LP_CONFIG_SNIPPET.html`
2. ページ末尾の HTML ブロックに `day034/source/script.js`

### 注意
- `pdfDownloadUrl` は WordPress のPDF URLに変更
- JSを入れないと、PDF完了表示・UTM引き継ぎ・計測イベントが動かない

## 7. 動作確認
1. 公開ページを開く
2. PC表示確認
3. SP表示確認
4. 予約CTAをクリック
5. PDFフォームを送信
6. PDFリンクを開く
7. 法務リンクを開く

## 8. 計測確認
1. GA4リアルタイムを見る
2. 予約ボタンを押す
3. PDFフォームを送る
4. `page_view`
5. `select_counseling_cta`
6. `generate_lead`
を確認する

## 9. 作業完了後
1. クライアントへ完了報告
2. `lpadmin` の扱いを案内
   - パスワード変更
   - アカウント削除
