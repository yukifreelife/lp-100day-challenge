# Day070 ネイルサロンLP - AI画像生成プロンプト

## 使用方法
このプロンプトをAI画像生成ツール（Midjourney、DALL-E、Stable Diffusionなど）に入力して、ネイルデザイン画像を生成してください。

**推奨設定**:
- アスペクト比: 1:1 (正方形)
- 解像度: 最低1024x1024px
- スタイル: 写実的、プロフェッショナル撮影

## 生成後の処理

1. **サイズ調整**: 正方形（1:1）にトリミング
2. **ファイル名**: `nail-01.jpg`, `nail-02.jpg`, ... のように連番で保存
3. **配置**: `day070/images/gallery/` に保存
4. **HTML更新**: 生成した画像ファイル名で `src` 属性を更新

## プロンプトのカスタマイズ

- **色を変更**: "pink" → "red" / "blue" / "green" など
- **長さを変更**: "short" → "long" / "medium"
- **スタイル**: "French manicure" → "solid color" / "gradient" / "glitter"
- **雰囲気**: "elegant" → "cute" / "edgy" / "minimalist"
