# Day070 - Nail Salon LP

個人事業主が運営するネイルサロンのLP。ギャラリー重視型で、ネイルデザイン作品をメインコンテンツとして配置し、視覚的魅力で予約獲得を促進する。

## コンセプト

「あなたの指先に、季節の魔法を」

- ビジュアルギャラリーでデザインを訴求
- 2〜3週間持つ美しさを約束
- リラックスしたサロン空間での特別な時間

## ターゲット

- 20〜40代女性
- ネイルに関心があり、定期的に利用している
- デザイン性を重視し、トレンド感度が高い

## 構成

1. **FV**: メインビジュアル、キャッチコピー、CTA
2. **Gallery**: フィルター付きネイルデザインギャラリー
3. **Menu**: 料金プラン、オプション
4. **About**: ナビスト紹介、こだわり
5. **Flow**: ご予約〜施術の流れ
6. **Contact**: 予約方法、アクセス、SNS

## デザインポイント

- カラー: ソフトピンク系（#f8c5d5）を基調
- フォント: Noto Sans JP
- レイアウト: ギャラリーをメインにしたビジュアル重視
- インタラクション: フィルター、モーダル、スムーズスクロール

## 技術

- HTML5
- CSS3（CSS Variables, Grid, Flexbox）
- Vanilla JavaScript（フィルター, モーダル, アニメーション）
