## Day078の目的

訪問型管理栄養士サービスのLP制作：
- 個人事業主としての信頼性・専門性の訴求
- 「自宅に来てもらえる」利便性の強調
- 食事改善の具体的イメージ提供
- 子育て家庭・中高年層への訴求

## セクション構成

1. **Hero** - メインビジュアル、キャッチ、こんな悩みありませんか、CTA
2. **Problem** - よくある食事の悩み（何を食べればいい・続かない・家族全員違う）
3. **Service** - 3つのプラン（食事記録チェック・冷蔵庫診断・家族別プラン）
4. **Feature** - 訪問型ならではのメリット（冷蔵庫チェック・一緒に料理・家族対応）
5. **Flow** - 初回訪問からフォローまでの流れ
6. **Profile** - 管理栄養士紹介（実績・資格・想い）
7. **Voice** - お客様の声
8. **FAQ** - よくある質問
9. **Contact** - 無料相談予約フォーム
