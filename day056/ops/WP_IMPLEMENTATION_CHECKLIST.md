## 3. よくある相談内容セクション

- [ ] スペーサーブロックを追加（セクション間の余白）
- [ ] 見出しブロックを追加
- [ ] H2に設定：「よくある相談内容」
- [ ] 段落ブロックを追加
- [ ] 本文を入力：「採用専任者がいない中小製造業で、以下のようなお悩みをお持ちではありませんか。」
- [ ] リストブロックを追加（箇条書き）
- [ ] 悩みリストを6件入力：
  - 求人を出しても応募が来にくい状態が続いている
  - 応募があっても、会社見学や次の接点につながりにくい
  - 仕事内容や職場の雰囲気がうまく伝わっていない感覚がある
  - 採用側でも、何を優先して見直すべきか整理しきれていない
  - 発信したい気持ちはあるが、何を出すべきか整理できていない
  - 会社の雰囲気や働く人の様子が十分に伝わっていない
- [ ] 段落ブロックを追加（2段落目）
- [ ] 本文を入力：「こうした課題は、求人原稿だけでは完結しないことが多いです〜（全文）」
- [ ] 段落ブロックを追加（3段落目）
- [ ] 本文を入力：「ミチル採用企画では、まず現状を整理することから支援を始めます〜（全文）」
