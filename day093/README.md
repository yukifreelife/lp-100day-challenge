# NemuNote Day093

Vite React + Tailwind scaffold for the NemuNote Japanese sleep app rebuild.

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Worker G Scope

Worker G owns only the root scaffold and global style files:

- `package.json`
- `package-lock.json` when generated by `npm install`
- `index.html`
- `vite.config.js`
- `tailwind.config.js`
- `postcss.config.js`
- `.gitignore`
- `README.md`
- `src/main.jsx`
- `src/index.css`

`App.jsx`, data files, and components are intentionally left for other workers.

## QA Notes

- Tailwind is installed locally through npm; the Tailwind CDN is not used.
- Browser Use will be used for desktop and mobile QA after the page implementation is assembled.
