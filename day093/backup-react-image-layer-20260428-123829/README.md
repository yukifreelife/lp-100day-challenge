# NemuNote Day093

Vite React implementation for the NemuNote Japanese sleep app LP mockup set.

## Setup

```bash
npm install
npm run dev
```

## Files Owned By Worker E

- `package.json`
- `index.html`
- `vite.config.js`
- `README.md`
- `docs/*`
- `src/*`
- `public/mockups/*`
- `public/assets/*`

## Notes

- Tailwind CSS is installed locally for the React project configuration.
- React source files under `src/` are part of the Day093 implementation.
- The Vite entry is expected at `src/main.jsx`.
- The visible UI is intentionally the generated mockup image layer plus transparent hotspots for pixel fidelity.
