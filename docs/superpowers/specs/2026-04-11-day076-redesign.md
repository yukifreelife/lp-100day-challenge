# Day076 LP デザイン改善仕様書
## Simple Space | ダイナミックタイポグラフィデザイン

**日付**: 2026-04-11
**ステータス**: 承認済み
**アプローチ**: アプローチA - 断層タイポグラフィ

---

## 1. 概要

### 目標
- 「テンプレート感」を脱却
- ダイナミックな視覚的インパクトを実現
- タイポグラフィをメインビジュアルとして活用

### コンセプト
**"Before & After in Typography"**
文字そのものが「変化」を伝えるビジュアルとなるデザイン

---

## 2. Heroセクション

### 構造
```
┌─────────────────────────────────────────────────────────┐
│ [nav] Simple Space (黒背景、白テキスト)                    │
├──────────────┬──────────────────────────────────────────┤
│              │                                           │
│  BEFORE      │               AFTER                      │
│  [写真]      │               [写真]                      │
│  暗い・散ら   │               明るい・整う               │
│              │                                           │
│              │    ┌─────────────────────┐               │
│              │    │  散らかった部屋が     │               │
│              │    │     1日で            │               │
│              │    │     変わる           │               │
│              │    └─────────────────────┘               │
│              │                                           │
│              │    [無料相談を予約する]                   │
└──────────────┴──────────────────────────────────────────┘
```

### 仕様

| 項目 | 仕様 |
|------|------|
| 分割比 | 50:50 垂直分割 |
| 高さ | 100vh |
| Before側 | 写真 + rgba(0,0,0,0.3) オーバーレイ |
| After側 | 写真 + 明るめフィルター |
| テキスト配置 | After側中央、vh単位 |
| CTA | After側下部、白ボタン |

## 4. タイポグラフィ

### フォントスケール

```css
--font-hero: clamp(3rem, 10vw, 12rem);  /* 超大型 */
--font-h1: 4rem;
--font-h2: 2.5rem;
--font-h3: 1.5rem;
--font-body: 1rem;
--font-caption: 0.875rem;
```

### ウェイト

- 見出し: 700
- サブ見出し: 500
- 本文: 400

### 特徴

- **vw単位使用**: ヒーローはviewport基準
- **行間狭め**: line-height: 1.1〜1.3
- **字間調整**: letter-spacing: -0.02em（密に）

---

## 5. レイアウト構造

### セクション構成

1. **Hero**: 分割レイアウト、タイポグラフィ主導
2. **Problem**: 3カード横並び、黒背景
3. **Solution**: 非対称グリッド（数字を超大型に）
4. **Service**: 横スクロールカード
5. **Before/After**: スライダーギャラリー
6. **Voice**: 引用マーク超大サイズ
7. **Flow**: 横一列ステップ
8. **Profile**: 黒背景のカード
9. **FAQ**: 黒背景アコーディオン
10. **Contact**: 分割レイアウト

### 背景パターン

- 黒セクション: Hero, Problem, Solution, Profile, FAQ
- 白セクション: Service, Before/After, Voice, Flow, Contact

## 6. アニメーション

### 定義

| 要素 | アニメーション |
|------|----------------|
| Heroテキスト | フェードイン + スライドアップ (0.6s) |
| 見出し下線 | 左から右へ伸長 (0.8s) |
| カード | スタッガーフェードイン (0.1sおき) |
| CTAホバー | スケール1.05 + シャドウ |
| Before/After | ホバーで分割線移動 |

### 実装

```css
/* 見出し下線アニメーション */
.section-title::after {
  content: '';
  position: absolute;
  bottom: -8px;
  left: 0;
  width: 0;
  height: 4px;
  background: var(--color-accent);
  animation: underlineExtend 0.8s forwards;
}

@keyframes underlineExtend {
  to { width: 100px; }
}
```
