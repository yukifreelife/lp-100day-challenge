# メタ評価 - Day076 LP (Template Feel & Originality)

**評価日:** 2026-04-12
**対象:** Simple Space | 散らかった部屋が、1日で変わる

---

## 1. LPの役割・目的分析

### LP本来の機能に対する評価

| 機能 | 評価 | 詳細 |
|------|------|------|
| コンバージョン誘導 | **B+** | CTボタンは配置適切だが、無料相談の心理的ハードル下げが不十分 |
| 信頼構築 | **A** | 実績数字、資格表示、お客様の声で一定の信頼を構築 |
| 差別化 | **B** | 「1日で変わる」「二度と散らからない」は他社と被りやすい |

### 強み

1. **ビフォーアフターの視覚的訴求**
   - スプリットスクリーンヒーローで即座にサービス価値を伝達
   - インタラクティブな比較スライダーが体験価値を高める

2. **証拠提示の多層構造**
   - 「100件以上の実績」「98%満足」という数字
   - お客様の声（3件）
   - 整理収納アドバイザー資格など専門性の表示

### 改善余地

1. **コンバージョンポイントの弱さ**
   - 無料相談への動機付けが「無料」だけ
   - 「相談する」というアクションの心理的ハードルを下げる要素不足
   - 例：「診断コース（無料）」の具体的価値が不明

2. **ターゲットの精緻化不足**
   - 「仕事や育児で忙しい」は広すぎる
   - より具体的なペルソナ（例：30代共働き女性、単身赴任中の男性など）への訴求が弱い

---

## 2. マーケティング視点評価

### ターゲット層の明確さ: C+

- 「仕事や育児で忙しい」「多くのお客様」 → 抽象的
- 具体的な生活シーン（朝の支度が30分短縮、引っ越し後の片付け）はお客様の声で出ているが、メイン Copy で活かせていない
- 改善案：ターゲットを冒頭で明示。「共働き世帯のクローゼット」「シングルライフの部屋」など

### 痛みの捉え方: B

- 3つの悩み（時間がない、どこから手をつけていいか、リバウンド不安）は的確
- しかし「なぜ片付けられないのか」という深層心理に触れられていない
  - 例：「過去に失敗した」「親の片付け方を強要される」「モノとの別れが辛い」など

### 競合との差別化: C

- 「1日で変わる」「二度と散らからない」は業界標準レベル
- 他の整理収納サービスでも同様の表現が見られる
- 独自性が出ていない:
  - 作業者の性格/手法の特徴
  - 特定の部屋/ジャンルへの特化
  - アフターフォローの具体性

### CVポイント最適化: C+

| 要素 | 現状 | 問題点 | 改善案 |
|------|------|--------|--------|
| CTA Copy | 「無料相談を予約する」 | 行動が重い | 「3分で診断する」「今すぐ空き状況を見る」 |
| 心理的ハードル | 高い | 相談＝悩み confession の印象 | 「診断」「チェック」という neutral な表現 |
| 緊急性 | なし | いつでも予約可 | 「今月限定」「先月平均3日で埋まった」など |
| 信頼保証 | あり | 資格・実績 | 具体的な Before/After の詳細（何をどう変えたか） |

## 3. オリジナリティ診断

### テンプレート感の程度: **中程度（6/10）**

### テンプレート的な要素

| 要素 | テンプレート感 | 具体的該当箇所 |
|------|----------------|----------------|
| セクション構成 | 高 | Problem → Solution → Service → Before/After → Voice → Flow → Profile → FAQ → Contact |
| 色使い | 中 | ミントグリーンは爽やかだが、整理収納サービスでは一般的 |
| Copy 表現 | 高 | 「1日で変わる」「98%満足」「無料相談」はどこでも見られる |
| アイコン | 中 | SVG で自作しているが、時計・はてな・循環は汎用的 |

### オリジナルな要素

| 要素 | オリジナリティ | 具体的該当箇所 |
|------|----------------|----------------|
| スプリットヒーロー | 高 | Before/After を左右分割で同時に表示 |
| インタラクティブスライダー | 高 | ドラッグで比較体験できる |
| カラーの統一感 | 中 | ミントグリーンのシステム化は丁寧だが色の選択は保守的 |
| グラスモーフィズム | 中 | overlay や badge で使用しているが、2020年代半ばのトレンド |

### 類似LPとの比較

整理収納サービスの一般的な構成:
- ヒーロー（メイン Copy + 背景）
- お悩み
- 解決策
- 料金プラン
- お客様の声
- よくある質問
- お問い合わせ

Day076 はこの基本構造に + Before/After スライダー + Profile + Flow が加わっているが、これは「あると嬉しい」レベルの差異で、「ないと困る」レベルの独自性ではない。

## 4. 属人性評価

### 作り手の個性: **C（弱い）**

### 個性が感じられない点

1. **Copy が汎用的**
   - 「散らかった部屋が、1日で変わる」 → どこのサービスでも言えそう
   - 「お客様一人ひとりのライフスタイルに合わせた」 → 文面上の標語に近い

2. **アドバイザー紹介が事実の羅列**
   - 資格、実績数、モットーは記載されているが
   - どんな人がどういう片付け哲学を持っているかが見えない
   - 例：具体的なエピソード「これまで一番大変だった現場は」「私自身がかつて散らかり放題だった」

3. **写真の雰囲気が伝わらない**
   - `images/advisor.jpg` はプレースホルダー扱い
   - 作業中の写真や実際の現場の雰囲気が見えない

### 個性を高める提案

| 項目 | 現状 | 改善案 |
|------|------|--------|
| ヒーロー Copy | 汎用 | 「毎日着る服が決まらない、をなくしました」など具体性 |
| Profile | 資格の羅列 | 片付け哲学、実体験、失敗談 |
| Voice | 評価のみ | 「担当者の方が明るくて楽しかった」など人柄が出る声 |
| Before/After | 画像のみ | 「ここをこう変えました」というプロセス解説 |

## 5. 具体的な改善提案（優先度順）

### 優先度1: コンバージョン率向上（マーケティング視点）

#### 1.1 CTA Copy の改善
```diff
- 無料相談を予約する
+ 3分であなたの片付け診断
+ 今なら無料で収納チェックリストプレゼント
```

#### 1.2 緊急性の付与
- 「今月予約で先着5名様に〇〇プレゼント」
- 「先月は平均3日で予約が埋まりました」

#### 1.3 コース選びのサポート
- 診断コースの価値を明確化：「30分であなたの片付け方を丸わかり诊断」

### 優先度2: ターゲットの明確化（マーケティング視点）

#### 2.1 ペルソナの冒頭提示
```
「共働きで忙しいご家庭のクローゼット」
「引っ越し後の片付けにお困りの単身者」
「子供のものが増え続けているママ」
```

#### 2.2 具体的な生活シーンの Copy 化
```
Before: 「片ける時間がない」
After: 「朝、服を選ぶだけで10分かかっていたのが...」
```

### 優先度3: 独自性の強化（オリジナリティ視点）

#### 3.1 独自メソッドの命名
- 「Simple Space Method™️」など
- 具体的な5ステップなどのプロセス化

#### 3.2 Before/After のプロセス開示
- 単なる Before/After ではなく、「どう変えたか」を開示
- 「この1枚の写真から始まった」というストーリー

### 優先度4: 属人性の強化（信頼構築）

#### 4.1 アドバイザーのストーリー化
```
「私自身、かつては散らかり放題でした。
ある時、友人の家に行って『いつもこんなに綺麗なの？』と聞かれたのがきっかけで...」
```

#### 4.2 作業中の写真掲載
- 実際に作業している様子の写真
- お客様との対話シーン

#### 4.3 Voice の人柄化
```
「担当の山田さんが明るくて、片付けが楽しく感じた」
「自分に合う収納方法を見つけるのが本当に楽しかった」
```

## 7. 総合評価

| 観点 | スコア | コメント |
|------|--------|----------|
| LPの役割・目的 | B+ | 基本機能は果たしているが、CV強化の余地あり |
| マーケティング視点 | C | ターゲットと差別化が弱い |
| オリジナリティ | C | ビジュアルは良いが、コンテンツがテンプレート的 |
| 属人性 | C | 作り手の個性がほぼ伝わっていない |

### 総評

Day076 の LP は、ビジュアルデザインと実装品質は高い（7.5/10）が、**コンテンツの独自性と属人性が弱い**。

特に問題なのは:
1. Copy が業界標準的で、記憶に残らない
2. ターゲットが抽象的で、「自分ごと」と感じにくい
3. 競合との差別化ができていない

**最も大きな改善の機会は「独自の片付けメソッドの確立」と「アドバイザーのストーリー化」にある。**

これらを強化することで、テンプレート感からの脱却とコンバージョン率の向上が同時に達成できる。
