# Day079 デザイン仕様書 - CodeKids LP

## プロジェクト概要

| 項目 | 内容 |
|------|------|
| サービス名 | CodeKids |
| カテゴリ | 教育（小学生向けプログラミング教室） |
| ターゲット | 小学生（6-12歳）とその保護者（30-50代） |
| コンセプト | 「ゲームばかりの子が、創る子に変わる」 |
| LPタイプ | Conversion型（問い合わせ・資料請求獲得） |

## コンセプト設計

### メインメッセージ
「ゲームばかりの子が、創る子に変わる」
- 消費から創造へ
- 受動遊戯から能動学習へ
- 保護者の不安（ゲーム依存）を希望（創造的スキル）に変換

### ビジュアルコンセプト
- **明るさ**: 教育・子供向けに適した親しみやすい雰囲気
- **信頼感**: 保護者に安心感を与えるプロフェッショナルな印象
- **革新性**: テクノロジーと創造性を融合した未来的なイメージ
- **温かみ**: 人間味のある指導風景、子供の笑顔

#### 共通仕様
```css

  transform: translateY(-4px);
```

#### Bento Gridカード
- 異なるサイズ（1x1, 2x1, 2x2）を組み合わせ
- 重要なコンテンツを大きく表示
- レスポンシブでSP時は1列化

### アニメーション仕様

| 要素 | アニメーション | 持続時間 | イージング |
|------|--------------|----------|-----------|
| スクロールフェードイン | 下から上に浮き上がり + 透明度変化 | 600ms | cubic-bezier(0.4, 0, 0.2, 1) |
| CTAパルス | 2秒ごとの拡大縮小（影） | 2s infinite | ease-in-out |
| カードホバー | 上昇 + 影強化 + 微細な傾き | 300ms | ease-out |
| FAQ開閉 | スムーズな高さ変化 + アイコン回転 | 300ms | ease-in-out |
| ヒーローフロートカード | 上下浮動（カードごとに遅延） | 3s infinite | ease-in-out |
| 数字カウントアップ | 0から目標値へ | 1500ms | ease-out |
| マグネットボタン | マウスに引き寄せられる | 100ms | ease-out |

#### reduced-motion対応
```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

## 2026年トレンド対応

### 1. Bento Grid Layout
**採用箇所**: カリキュラム・サービス紹介セクション

```html
<div class="bento-grid">
  <div class="bento-item bento-2x2">メインコンテンツ</div>
  <div class="bento-item bento-1x1">サブコンテンツ1</div>
  <div class="bento-item bento-1x1">サブコンテンツ2</div>
  <div class="bento-item bento-2x1">横長コンテンツ</div>
</div>
```

- 非対称グリッドで視覚的リズムを作る
- 情報の重要度に応じたサイズ配分
- SP時は1列スタックに変形

### 2. Micro-interactions

**ボタン系**
- ホバー時の微妙な色変化
- マグネット効果（マウスに引き寄せ）
- クリック時のリップルエフェクト

**カード系**
- 3D Tilt効果（マウス位置に応じた傾き）
- ホバー時の情報展開
- フローティングアニメーション

**スクロール系**
- パララックス効果（背景と前景の速度差）
- スクロールトリガーアニメーション
- プログレスバー表示

### 3. Dark Mode
- システム設定に自動連動
- 手動切り替えスイッチ（オプション）
- コントラスト比確保（WCAG AA準拠）

### 4. モーションデザイン
- 意図的な動きで注意を誘導
- 過度な動きは排除（教育コンテンツとしての適格性）
- 読み込み時のプログレッシブエンハンスメント

## アクセシビリティ

### 必須対応項目

| 項目 | 対応内容 | 優先度 |
|------|----------|--------|
| コントラスト比 | WCAG AA準拠（4.5:1以上） | 必須 |

| キーボード操作 | 全機能 Tab / Enter / Esc で操作可能 | 必須 |
| reduced-motion | ユーザー設定を尊重 | 必須 |
| 代替テキスト | 画像には意味のあるalt属性 | 必須 |
| 見出し階層 | H1→H2→H3の論理構造 | 必須 |

- 音声読み上げソフト最適化
- 高コントラストモード対応
