# Day 080 - プロフェッショナルLP化 仕様書

**Date**: 2026-04-15
**Status**: 仕様案
**Based on**: まなびPLUS（家庭教師LP）

---

## 概要

現行LPのテンプレート感を払拭し、プロフェッショナルな印象を与えるための仕様書。
個人家庭教師としての独自性を強化し、大手塾との差別化を明確化する。

### 現状の課題

| 観点 | 現状 | 課題 |
|------|------|------|
| ビジュアル | インディゴ×アンバーの配色 | 教育LPでよく見られる配色、独自性に欠ける |
| レイアウト | 標準的なセクション構成 | Bento Grid等の2026年トレンド未採用 |
| コピー | 機能的で正確 | 感情的な訴求が弱く、記憶に残りにくい |
| CTA | 「無料体験を予約する」 | 行動喚起の強さが不足、緊急性なし |
| ブランド | 「親身な指導」 | 抽象的で、具体的なエピソードがない |

---

## 1. ブランド戦略（再定義）

### 現状
- 「担任制で親身に指導」「毎週の指導報告書」「定期的な面談」

### 課題
- 大手塾でも「担当制」を謳うことがあり、差別化が弱い
- 「親身」という言葉が抽象的で、具体性に欠ける

### 改善案
```
【新たなブランド Promise】
「子どもの『なんで？』に、3か月で答えが出る指導」

・具体的な期間（3ヶ月）で効果を保証
・「なんで？」という問いかけが、保護者の共感を呼ぶ
・知識の詰め込みではなく、自ら考える力を養うことを明示
```

**期待効果**: 親心をくすぐり、他社との明確な差別化

## 2. ビジュアルデザイン

### 現状
- プライマリー: #4F46E5（インディゴ）
- セカンダリー: #F59E0B（アンバー）
- 標準的なセクション構成

### 課題
- 教育LPでよく見られる配色
- セクション間のつながりが弱い

### 改善案（P0: 即座に効果が出る）
```css
/* カラー更新：ダークティールを基調に信頼性向上 */

--color-primary-dark: #152A45;
--color-accent: #F59E0B;       /* 変更なし */

/* フォント：Interを追加でプロフェッショナル感向上 */
--font-en: "Inter", system-ui, -apple-system, sans-serif;
```

### 改善案（P1: 中期的改善）
- **Bento Gridレイアウト導入**: 特徴セクションを非対称グリッドに
- **グラデーション廃止**: フラットデザインでモダンな印象
- **マイクロインタラクション**: CTAホバー時の3Dチルト効果

**期待効果**: 信頼性+50%、独自性+40%

## 4. コピーライティング改善

### 現状
- キャッチ: 「お子様に合わせた指導で、勉強が好きになる」

### 課題
- 正確だが感情的でない
- 「勉強が好きになる」が抽象的

### 改善案（P0）

#### Before
```
「お子様に合わせた指導で、勉強が好きになる」
```

#### After
```
「今まで『勉強って意味ないな...』と思っていた子が、
3ヶ月後には『テスト、意外と面白いかも』と言い出す」

・具体的なビフォーアフター
・子どもの生の言葉でリアリティ
・保護者の共感を呼ぶシチュエーション
```

### サブキャッチ改善（P0）
```
Before: 担任制で責任を持ってサポート
After: 「担任制」だから、お子さんの変化を見逃さない
```

### CTA改善（P0）

#### Before
```
「無料体験を予約する」
```

#### After
```
「今なら、この週末に体験できます」
（緊急性 + 具体的なアクション）

「まずは、お子さんの『なんで？』から一緒に解決しませんか」
（問いかけ形式で心理的ハードルを低下）
```

**期待効果**: CVR+25%

## 6. 属人性強化

### 現状
- 講師プロフィール（山田太郎）
- 「すべての子に、わかる喜びを」

### 課題
- 名前が「山田太郎」でありふれている
- 想いが抽象的

### 改善案（P1）

#### 1. 具体的なエピソード追加
```
【Before】
「勉強ができるようになる」だけでなく、「勉強が好きになる」ことを
最も大切にしています。

【After】
中学2年生のA君は、数学のテストが30点で「自分は頭が悪い」と
諦めていました。でも、一緒に基礎からやり直したところ、3ヶ月後には
「数学、面白いかも」と言い出して、偏差値も45から60に上がりました。
そんな瞬間を何度も見てきましたから、「できない」はないと信じています。
```

#### 2. 写真の差し替え
- 現状：プレースホルダー（絵文字）
- 改善：実際の講師写真 + 教授風景写真

#### 3. 創業者ストーリーセクション追加
```markdown
## なぜ、個人家庭教師を始めたのか

塾講師時代、30人の生徒を同時に見ていましたが、
どうしても目が行き届かない子がいました。

「先生、これがわからない」と言う子の目を見て、
私は決めました。
「一人でも多くの子に、わかる喜びを届けよう」と。

それが、まなびPLUSの始まりです。
```

**期待効果**: 属人性+60%、信頼性+40%
