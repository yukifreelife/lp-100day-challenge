# Day040 - Phase2 着手計画

## 現在の前提
- 公開URLの主要導線は動作確認済み
  - 予約CTA -> TimeRex
  - PDFフォーム送信 -> 確認画面（ロボットチェック） -> PDF表示
  - 案内メール到達
  - 法務リンク到達
- クライアントからは公開品質OKを受領済み
- 追加改善候補は `Medium 1 / Low 2` として次回調整へ整理済み

## Phase2 の目的
- 初回公開の安定性を崩さずに、計測と導線設計を再開する
- 次回調整候補を、場当たりではなく役割整理にもとづいて反映できる状態にする

## 着手順
1. JS注入経路の再確認
   - `WPCode Lite` の `Forbidden access` が今も続くかを確認する
   - 続く場合は、別経路でのJS投入案を先に決める
2. PDF導線の役割定義
   - 無料相談前段の教育導線か
   - ライトユーザー向けの独立入口か
   - どちらを優先するか決める
3. 計測の最小復旧範囲を確定
   - UTM引き継ぎ
   - GA4 基本計測
   - Meta 基本計測
   - 詳細イベントは Phase3 に残す
4. 表示微調整の順番を決める
   - FV本文圧縮 / CTA間隔
   - 中間CTA余白
   - PDFフォーム注記の見せ方

## 着手前の判断ポイント
- 先に導線の役割を決めずに計測だけ戻すと、イベント設計をやり直す可能性がある
- 逆に JS注入経路が確保できないままでは、UTM / GA4 / Meta の復旧設計が机上で止まりやすい
- そのため、最初の判断は `JS注入経路` と `PDF導線の役割` の2本を優先する

## Day040 時点の推奨順
1. `WPCode Lite` / 別経路で JS を戻せるか確認
2. PDF導線の役割を1文で定義
3. UTM / GA4 / Meta の最小復旧案を作る
4. その後に FV / CTA / PDF注記の微調整へ入る
