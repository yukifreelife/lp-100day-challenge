# Day069 - カメラマン個人紹介LP

個人事業主（カメラマン）が自身のサービスを紹介・集客するためのLP。

## コンセプト
「瞬間の美しさを切り取り、あなたの物語を紡ぐ」をテーマに、ナチュラルで温かみのある写真を提供するフォトグラファーのブランディングLP。

## ターゲット
- 結婚式を控えたカップル（ウェディング撮影）
- 就職・転職活動中の個人（プロフィール撮影）
- 商品・店舗の写真が必要な事業者（ビジネス撮影）

## 構成
1. **FV**: キャッチコピー + イメージ背景
2. **About**: 自己紹介・経歴・写真家としての哲学
3. **Services**: 3つのサービス（Wedding / Profile / Business）
4. **Portfolio**: カテゴリ別作品ギャラリー
5. **Price**: 3つの料金プラン
6. **Voice**: お客様の声
7. **FAQ**: よくある質問
8. **Contact**: お問い合わせフォーム

## デザインポイント
- 色彩: アースカラーを基調としたナチュラルなトーン
- フォント: 見出しにセリフ体で高級感を演出
- レイアウト: 余白を活かした洗練された構成
- インタラクション: タブ切り替え・アコーディオン

## 技術
- HTML5
- CSS3（CSS Variables, Grid, Flexbox）
- Vanilla JavaScript（タブフィルター, アコーディオン, フォームバリデーション）
