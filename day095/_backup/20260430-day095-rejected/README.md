# Day095 - MiraSkill AI

MiraSkill AI is a fictional landing page for a Japanese AI reskilling service for working adults.

## Concept

- Category: Education / AI reskilling
- Audience: working adults who want to use AI for current work, career change, or side work
- Main conversion: free AI aptitude diagnosis
- Stack: Vite + React + Tailwind CSS

## Key Files

- `src/App.jsx`: LP sections, diagnosis demo, FAQ interactions
- `src/index.css`: global styles, reveal animation, responsive utilities
- `public-optimized/assets/`: local SVG visual assets
- `design/`: tone, palette, and asset direction
- `docs/`: implementation plan, evaluation, improvement, work summary

## Verification

```bash
npm run build
```

The diagnosis form is a frontend demo. Production integration points are mail notification, CRM registration, and GA4 conversion events.
