# Day045 - 次フェーズ整理案の送付文面（一括コピー用）

```text
件名：LP公開後の次フェーズ整理案について

〇〇様

お世話になっております。
先日はご返信ありがとうございました。

次フェーズについて、現時点での整理案をまとめましたのでご共有いたします。

現在のLPは、大きな表示崩れや主要導線の問題なく公開できている状態ですので、
まず一定期間データを見たうえで、必要な改善だけを整理していく進め方がよいと考えております。

現時点では、以下の2案が進めやすいと考えております。

1. 初回計測レビュー・改善提案
   - 70,000円（税込）
   - 1〜2週間分の数値確認
   - 予約CTAやPDF導線の反応整理
   - 離脱しやすい箇所の仮説整理
   - 次アクションの簡易ご提案
   - 共有1回

2. LP改善伴走・月次レビュー
   - 120,000円（税込） / 月
   - 月次数値確認
   - ボトルネック仮説の更新
   - 改善優先順位の整理
   - 継続的な改善相談

現時点では、まず `1. 初回計測レビュー・改善提案` から始める形が、
必要な範囲を見極めやすく、進め方として自然かと考えております。
必要であれば、その後に月次レビューへ切り替える進め方も可能です。

もし問題なければ、上記どちらの形が近いかご希望を伺えれば、
その前提で開始時期や進め方を整理いたします。

引き続きよろしくお願いいたします。
```
