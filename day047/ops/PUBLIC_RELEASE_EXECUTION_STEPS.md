# PUBLIC_RELEASE_EXECUTION_STEPS

## 公開前ゲート
- `PRE_LAUNCH_CHECKLIST.md` の Blocked が 0
- 主要CTAが通る
- 法務リンクが開く
- 本番受信先と通知先が確認済み

## 公開当日の手順
1. 本番URLで表示確認
2. スマホ実機または近い幅で主要導線確認
3. 主要CTAクリック確認
4. フォーム / 予約 / LINE の導線確認
5. 法務リンク確認
6. 必要なら GA4 / Meta の発火確認
7. クライアントへ公開URLと確認項目を送る

## fallback ルール
- 一部計測が未反映でも、`内容が読める / 主要CTAが動く / 法務リンクが通る` なら公開優先は可
- ただし、何を妥協したか、後続で何を直すかをクライアントへ明示する

## 公開時に残す証跡
- 本番URL
- スマホ表示キャプチャ
- 主要CTA導線の確認メモ
- フォーム通知または予約導線の確認メモ
