# handoff（証跡ログ）

**使う場面**: 合意、変更、保留、リスク、依頼、回答を時系列で残すとき

## 目的
- 判断の理由と次アクションを追跡できる状態にする。

## 固定前提
- 案件名: 製造業向け採用支援サービス LP 相談
- クライアント名: ミチル採用企画 秋山様
- 主CV: 無料相談予約
- 納品形態: 既存 WordPress 固定ページ想定
- 公開方式: WordPress 既存サイト内反映を第一候補。テーマ / ビルダー制約次第で代替案あり
