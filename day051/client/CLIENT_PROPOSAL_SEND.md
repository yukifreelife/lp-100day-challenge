# CLIENT_PROPOSAL_SEND

## 件名案
- LP制作と公開支援の進め方について

## 本文たたき
- ご相談内容を踏まえ、今回は `LP制作` `WordPress反映 / 公開支援` `公開直後の軽微修正` を分けて整理する前提でご提案します。
- 理由は、公開方法と運用方法によって工数と責任範囲が大きく変わるためです。
- 先に公開方式を確認したうえで、どこまでを今回の制作範囲に含めるかを明確にしたいです。

## 提案時に外さない要素
- 主CV と副CV の整理
- WordPress 実装方式の確認
- 含む / 含まない の明記
- 軽微修正の回数または期間
- 計測整備とレビューを別フェーズにする説明
