# Day037 WordPress 公開実行手順

## 目的
- 初回公開に必要な WordPress 側の操作を、最短順で実行する。
- 今回の追加要件:
  - PDFフォームへ `reCAPTCHA` 注記を入れる
  - 固定ページの保護解除
  - 必要ならトップURLを LP に切り替える

## 対象ページ
- 第一候補:
  - ID `36`
  - タイトル: `WP固定ページ納品用`
- 代替候補:
  - ID `8`
  - タイトル: `LP初稿（確認用）`

## 実行順
### 1. ログイン
1. `https://yuki-freelife.com/lp-review/wp-admin/` を開く
2. `lpadmin` でログインする
3. `SiteGuard` のログインCAPTCHAを通過する

### 2. LP本体の固定ページを確定
1. `固定ページ` 一覧を開く
2. `WP固定ページ納品用` を開く
3. もし内容が古い、または別ページを使うべきなら `LP初稿（確認用）` を比較する
4. 今回の公開先ページを1つ決める

### 3. PDFフォームへ注記を反映
1. ページ編集画面で PDF セクションを探す
2. 現在の `<form class="pdf-form" ...>` から `</form>` までを置き換える
3. 貼り付け元:
   - `/Users/yuuki/Works/lp-100/day037/PDF_FORM_RECAPTCHA_NOTE_OWNER_EMAIL.html`
4. 本番受信先へ戻すなら、`action` だけ公開用メールへ差し替える
5. `更新` を押す

### 4. パスワード保護を解除
1. 同じ固定ページの `公開状態` または `可視性` を開く
2. `パスワード保護` を解除する
3. `公開` または `更新` を押す

### 5. トップURLをLPへ切り替える
1. `設定`
2. `表示設定`
3. `ホームページの表示` を `固定ページ` にする
4. `ホームページ` に公開先として決めた固定ページを選ぶ
5. `変更を保存`

## 保存後の確認
1. `https://yuki-freelife.com/lp-review/` で LP 本体が開く
2. PDFフォーム下に
   `送信後に確認画面（ロボットチェック）が表示されます。`
   の注記が出ている
3. `無料PDFを受け取る` ボタンが表示される
4. FAQ が常時表示で読める
5. 予約CTAが TimeRex に飛ぶ
6. 法務ページリンクが開く

## 最終確認URL
- 原則:
  - `https://yuki-freelife.com/lp-review/`
- もしトップ切り替えをまだしていない場合:
  - 保護解除した固定ページの直接URLを確認用として使う

## 補足
- 管理画面更新が終わるまでは、クライアントへ「公開完了」とは案内しない
- 公開後の確認依頼は、トップURLが LP を表示していることを確認してから送る
