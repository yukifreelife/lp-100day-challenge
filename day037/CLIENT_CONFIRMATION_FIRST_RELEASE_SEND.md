# Day037 初回公開確認 送信用文面

```text
件名: LP初回公開前の最終確認（PDF受け取り導線について）

お世話になっております。
LPの初回公開について、現状の実装状況と確認いただきたい点を整理してご連絡します。

現在、LP自体の本文・画像・法務ページリンク・予約導線は公開できる状態まで進んでいます。
また、よくある質問（FAQ）も閲覧できる状態です。

ただし、初回公開を優先するため、一部の仕様を下記の形に変更しています。

1. FAQ
現在は「クリックで開閉」ではなく、最初から全件表示の仕様です。

2. PDF受け取り導線
現在は、お名前とメールアドレスを入力して送信すると、
確認画面（reCAPTCHA）が1回表示された後にPDFが開く仕様です。
そのため、「送信後すぐにページ内で完了表示される」形ではありません。

3. 計測まわり
初回公開では、UTM引き継ぎやGA4 / Metaの詳細イベント計測は入れていません。
まずは公開を優先し、必要であれば第2フェーズで追加する想定です。

このまま初回公開を進めるにあたり、PDF導線を次のどちらで確定するかご希望を確認させてください。

A. 名前・メール取得を優先する
- 現在のフォームを維持します
- 送信時に確認画面（reCAPTCHA）が1回入ります

B. 受け取りやすさを優先する
- フォームをやめて、PDFが直接開くボタンに変更します
- 確認画面はなくなります
- その代わり、名前・メールの取得は行いません

ご希望のパターンを、A または B でご返信ください。

補足:
- Aを選ぶ場合は、公開用の受信先メールアドレスへ戻す必要があります
- その場合、公開前に一度だけメール側で認証（Activate Form）が必要になる可能性があります

ご返信をいただけ次第、最終調整を進めます。
よろしくお願いいたします。
```
