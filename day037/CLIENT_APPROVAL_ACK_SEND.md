# Day037 クライアント承認後 返信用文面

```text
お疲れさまです。ご確認ありがとうございます。

内容、承知しました。
それでは、初回公開は「公開優先」の方針でそのまま進めます。

対応内容は以下で確定します。

- FAQは常時表示のまま進行
- 無料PDF導線は現在のフォーム送信方式を維持
- フォーム付近に
  「送信後に確認画面（ロボットチェック）が表示されます」
  の注記を追加
- UTM引き継ぎ・詳細イベント計測は初回公開では入れず、後続フェーズで対応

この内容で、
「予約できる・PDFが受け取れる・内容が読める」
状態を優先して公開準備を進めます。

公開完了後、確認用URLをお送りします。
スマホ確認で気になる点があれば、その時点でまとめていただければ次の調整に反映します。

引き続きよろしくお願いいたします。
```
