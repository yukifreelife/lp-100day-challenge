# Day037 初回公開 判断表

## 目的
- クライアント回答後に、そのまま次の作業へ移れる状態にする。
- 初回公開の判断を「公開優先」と「導線摩擦」の観点で整理する。

## 現在の前提
- FAQは常時表示で成立している。
- 予約CTAは `https://timerex.net/s/bodymake_tokyo_yuta` で成立している。
- PDFフォームは `FormSubmit` の通常POSTで動作する。
- `FormSubmit` はアクティベーション済みだが、送信時に `reCAPTCHA` が1回入る。
- 現在の受信先は仮で `yuki.freelife@gmail.com` になっている。

## 今回の確定結果
- クライアントは初回公開を優先する方針で承認済み。
- 今回は `A: フォーム維持` で進める。
- 追加対応は、フォーム付近に `送信後に確認画面（ロボットチェック）が表示されます` の注記を入れること。
- 公開後に確認用URLを送り、スマホでも確認してもらう。

## 判断パターン
### A: フォーム維持
- 向いている条件:
  - 名前とメールアドレスの取得を残したい
  - `reCAPTCHA` の1ステップ増加を許容できる
- 直後の作業:
  1. WordPress上のフォーム `action` を公開用受信先へ戻す
  2. 初回送信を1回行う
  3. 受信側で `Activate Form` が必要なら対応してもらう
  4. 再送信してPDF到達を確認する
- 主なリスク:
  - クライアント側のメール確認が必要
  - `reCAPTCHA` で離脱が増える可能性がある
- 完了条件:
  - 公開用受信先でフォーム送信後、PDF到達が確認できる

### B: PDF直リンク化
- 向いている条件:
  - 1クリックでPDFを開かせたい
  - 公開を最短で確定したい
- 直後の作業:
  1. WordPress上のPDFフォームを削除する
  2. PDF直リンクボタンへ置き換える
  3. PC / SPでリンク先PDF表示を確認する
- 主なリスク:
  - 名前とメールアドレスは取得できなくなる
- 完了条件:
  - ボタン押下でPDFが直接開く

## 公開判断の目安
- 集客リスト取得を優先するなら `A`
- 導線の軽さと公開速度を優先するなら `B`

## 第2フェーズで戻す候補
1. FAQの開閉式復活
2. UTM引き継ぎ
3. GA4 / Meta の詳細イベント
4. PDF送信後のLP内サンクス表示

## 返答を受けたら最初に確認すること
1. `A` / `B` のどちらで確定したか
2. `A` の場合、公開用受信先メールアドレスはどれか
3. 第2フェーズで優先したい項目があるか
