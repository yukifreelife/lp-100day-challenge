## 推奨画像ソース

- **Unsplash**: https://unsplash.com - 無料・商用利用可能
- **Pexels**: https://pexels.com - 無料・商用利用可能
- **Pixabay**: https://pixabay.com - 無料・商用利用可能

## 使用方法

1. 上記サイトから画像をダウンロード
2. 適切なサイズにリサイズ（推奨: 800x600px）
3. `day073/gallery/` ディレクトリに配置
4. `index.html` で自動的に読み込まれます
