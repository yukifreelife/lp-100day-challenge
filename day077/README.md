## セクション構成

1. **Hero** - メインビジュアル、キャッチ、悩みバッジ、CTA、緊急性バナー
2. **Problem** - よくある悩み3つ（時間がない・どこから手をつけて・リバウンド）
3. **Target** - 「こんなあなたに」セクション（★追加）
4. **Solution** - 解決策（1部屋から・プロの技術・維持方法、Simple Space Method™️）
5. **Service** - 3つのコース（診断・半日・1日フル）
6. **BeforeAfter** - ビフォーアフター事例 + プロセス開示
7. **Voice** - お客様の声
8. **Flow** - 予約から完了までの流れ
9. **Profile** - アドバイザー紹介（ストーリー化）
10. **FAQ** - よくある質問
11. **Contact** - 無料相談予約フォーム（簡素化）
