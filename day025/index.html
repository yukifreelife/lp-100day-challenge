LIVE PHASE TRACKER

PHASE 01 // FIRST IMPRESSION

最初の3秒で「読む理由」を作る。選択肢を絞り、視線と期待を固定する。

PHASE 01

説明より先に、視線の重力をつくる

冒頭は情報を削り、意味のある余白で「続きが気になる」を生む。

ファーストビューで情報過多を避け、まず体験温度を合わせる。理解は次のスクロールで段階的に渡す。

PHASE 02

課題は箇条書きではなく、流れで見せる

時間軸で痛みを見せると、読者の実感とページ体験が重なる。

困りごと→停滞→機会損失の順で整理し、解決策を受け入れる準備を整える。

PHASE 03

提案は読むものから、触って確かめるものへ

反応するUIで価値を体感化し、納得までの距離を短くする。

ホバー・クリック・ドラッグの反応で「効きそう」を瞬時に伝え、長文依存を減らす。

PHASE 04

押し切るCTAではなく、進みたくなるCTAへ

入力負荷を分割して、完了までの心理抵抗を小さくする。

一度に詰め込まず、各ステップに小さな完了感を置くことで送信完了率を上げる。

ORBIT PRIORITY SELECTOR

先にKPIを選ぶ。演出は、その目的に合わせる。

動きは飾りではなく機能。優先指標を選ぶと、中央の戦略が切り替わる。 成果に直結しない演出は切り落とし、効く演出だけを残す。

CV PRIORITY

入力障壁を減らし、送信完了率の最大化に集中する。

REACTION MODULES

触れた瞬間に、意図と価値が伝わるUI群

MAGNETIC CTA

迷いを減らす、吸着型CTA

押せる対象を直感で認識させ、クリック直前の迷いを短縮する。

CTA付近のノイズを減らし、押下の意思決定を1アクションで完了させる。

PHASE TRACK

現在地を示す、読了アシスト

進捗が見えると離脱は減る。残り距離を示し、読み切る動機を維持する。

先に完了見込みを提示し、長文に入る前の心理的ハードルを下げる。

INPUT SPLIT

入力は短く、連続的に進める

項目を一気に見せず、ミニステップで完了体験を積み上げる。

ステップ単位の達成感を作り、入力開始後の離脱率を段階的に下げる。

COMPARISON SLIDER

同じ情報でも、体験設計で成果は変わる。

STANDARD FLOW

読み順は明快。ただし、体験差は作りづらい

  • 説明→実績→CTAの直列導線
  • 整理しやすいが、記憶に残りにくい
  • CVは文言の強さに依存しやすい

INTERACTIVE FLOW

同じ情報量でも、理解と没入の順序を設計できる

  • 空気感→課題→反応UI→段階CVの構造
  • 読む前に「触って理解」が成立する
  • CTA前に心理抵抗を分割して軽減できる

左右に動かして、体験差を比較する

AXIS SHIFT SECTION

この区間だけ、縦スクロールを横展開に変える。

軸の切替で視線の惰性を断ち、読みのリズムを再起動する。 派手さのためではなく、要点の知覚率を高めるための演出。

VERTICAL -> HORIZONTAL

スクロール操作はそのまま。情報だけ横へ流す

操作負荷を増やさず、文脈切替だけを強く体感させる。

TIMING RESET

同じリズムで読ませ続けない

縦積みの惰性を断ち、重要メッセージの知覚率を上げる。

NARRATIVE EXTEND

1画面を「連続フレーム」に変える

フレーム送りの感覚で、理解を段階的に積み上げる。

RETURN TO VERTICAL

横演出の後に、縦導線へ自然に復帰

変化の記憶を残したまま、CV入力コンソールへ接続する。
