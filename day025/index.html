PHASE 01 // ATTENTION LOCK

最初の3秒は理解より空気を伝える。余計な選択肢を切り、視線を固定する。

PHASE 01

情報を足す前に、視線の重力を作る

冒頭は説明を削り、巨大タイポで「続きを見たい」を作る。

最初の視認範囲に選択肢を詰め込まず、視線の重力を先に作る。理解より没入を優先し、次のスクロール行動を誘発する。

PHASE 02

課題を箇条書きにしない。時間軸で見せる

課題を時系列で見せ、読者の体験記憶とページ体験を合わせる。

「困りごと→悪化→手詰まり」の流れで課題を整理し、次の解決策セクションへの受け入れ準備を作る。離脱を減らす狙い。

PHASE 03

提案は読むものではなく、触って確かめるもの

反応するUIで、提案価値を受け身ではなく能動的に理解させる。

ボタンやカードの状態変化を使って「効きそう」を疑似体験化。説明文の長文化を避け、短時間で納得を形成する。

PHASE 04

最後に押すのではなく、押したくなる負荷に分解する

入力負荷を分割し、送信完了までの心理的ハードルを下げる。

1画面に項目を詰めず、段階的に回答させることで「もう少しだけ進む」を積み重ねる。結果としてCV完了率を上げる。

ORBIT SELECTOR

何を伸ばすかを先に決める。演出はその後。

動きは目的のために使う。優先KPIを選ぶと、中央の戦略が切り替わる。 「なんとなく派手」を排除し、成果に効く演出だけ残す。

CV IMPACT

入力障壁を減らし、送信完了率を優先して設計。

REACTION MODULES

触れた瞬間に「理解」が返ってくるUI群

MAGNETIC CTA

カーソルに吸い付く行動ボタン

押せる対象を直感で認識。迷い時間を短縮し、クリックを即断に変える。

CTA周辺の要素を減らし、押下直前の迷いを削ることでCV率の安定化を狙います。

PHASE TRACK

読むほど進む進捗可視化

現在地がわかると離脱が減る。残り距離を見せて読了率を底上げ。

長文説明の前に進捗を見せることで、完読見込みを持たせて途中離脱を抑制します。

INPUT SPLIT

入力は短く、連続的に

大量項目を一気に見せず、ミニステップで完了体験を積み上げる。

ステップごとの完了感を作ることで、入力開始後の離脱率を段階的に下げます。

COMPARISON SLIDER

通常導線と体験導線を、同じ視点で見比べる。

STANDARD LP FLOW

読み順は明快だが、体験差は作りにくい

  • 説明→実績→CTAの直列導線
  • 情報は整理しやすいが印象が均一
  • CVは訴求文言への依存が大きい

EXPERIENCE LP FLOW

同じ情報量でも、理解と没入の順序を設計できる

  • 空気感→課題→反応UI→段階CVの構造
  • 読む前に「触って理解」が成立する
  • CTA前に心理抵抗を分割して軽減

左右に動かして違いを確認

AXIS SHIFT SECTION

ここだけ、縦スクロールが横展開に変わる。

セクションごとに軸を変えることで、視線の惰性を断ち切る。 ただ派手にするのではなく、読むテンポを再起動して次のCV導線へ戻す。

VERTICAL -> HORIZONTAL

スクロールは縦のまま、情報だけを横へ流す

操作負荷を増やさず、文脈切替だけを強く体感させる。

TIMING RESET

同じリズムで読ませ続けない

縦積みの惰性を切ることで、重要メッセージの知覚率を上げる。

NARRATIVE EXTEND

1画面を「連続フレーム」に変える

映画のようにフレームを送り、理解を段階的に積み上げる。

RETURN TO VERTICAL

横演出の後に縦導線へ復帰

変化の記憶を残したまま、コンソール型CV入力へ接続する。

MODE: VERTICAL FEED / HORIZONTAL ACTIVE
