PHASE 01 // ATTENTION LOCK

最初の3秒は理解より空気を伝える。余計な選択肢を切り、視線を固定する。

PHASE 01

情報を足す前に、視線の重力を作る

冒頭は説明を削り、巨大タイポと呼吸する背景で「続きを見たい」を発火させる。

PHASE 02

課題を箇条書きにしない。時間軸で見せる

ユーザーのストレスは連続体。連続演出で再現し、次の解決情報へ自然に接続する。

PHASE 03

提案は読むものではなく、触って確かめるもの

ホバーやタップで状態が変わるUIを使い、価値を受動から能動へ切り替える。

PHASE 04

最後に押すのではなく、押したくなる負荷に分解する

1フォーム完結をやめ、ステップ化して心理的抵抗を軽くしCVへ導く。

ORBIT SELECTOR

何を伸ばすかを先に決める。演出はその後。

動きは目的のために使う。優先KPIを選ぶと、中央の戦略が切り替わる。 「なんとなく派手」を排除し、成果に効く演出だけ残す。

CV IMPACT

入力障壁を減らし、送信完了率を優先して設計。

REACTION MODULES

触れた瞬間に「理解」が返ってくるUI群

MAGNETIC CTA

カーソルに吸い付く行動ボタン

押せる対象を直感で認識。迷い時間を短縮し、クリックを即断に変える。

PHASE TRACK

読むほど進む進捗可視化

現在地がわかると離脱が減る。残り距離を見せて読了率を底上げ。

INPUT SPLIT

入力は短く、連続的に

大量項目を一気に見せず、ミニステップで完了体験を積み上げる。
