# Day025 - 動きで惹きつける体験型LP（NEON ARC LP LAB）

## 概要
`day025`は、従来の業務的なLPから離れ、以下を主軸に設計した体験重視LPです。

- 映像感のある背景レイヤー
- スクロール連動で進むストーリー表示
- マイクロインタラクション（カード傾き、CTA反応）
- ステップ分割フォームによるCV導線

- `/Users/yuuki/Works/lp-100/day025/styles.css`

## 主要UI/UX要素
1. Hero内のシーン切り替え（Opening / Story / Proof / Action）
2. スクロール進捗バー + セクション連動
3. ストーリーセクションの4段階表示
4. 3D風ホバー反応カード
5. 3ステップ診断フォーム（その場要約付き）
6. モバイルメニュー、フォーカス可能なスキップリンク、`prefers-reduced-motion`対応
