# Day100 画像ライセンス評価

評価日: 2026-05-05  
スコア: **82 / 100**

## 良い点

- runtime画像は `public/assets/v2/` の個別生成素材として管理。
- mockup画像を1枚背景として貼る実装は見つからない。
- PNG/WebP/AVIFの派生関係が `asset-manifest-v2.md` と `ASSETS.md` に記録されている。
- 生成素材であること、公開前確認が必要であることを文書化している。

## 指摘

| 優先度 | 内容 | 影響 |
|---|---|---|
| P2 | `/image-gen` 生成時の参照画像と利用条件の証跡は完全ではない | 外部公開前の確認が必要 |
| P2 | raw/keyed/final/derivedの関係はあるが、生成プロンプトとの紐付けが弱い | 再利用時の追跡性がやや不足 |
| P3 | OGP SVGは自作扱いだが、SNS側の形式適合確認が必要 | 共有時表示の不確実性 |

## 優先改善

1. 生成時プロンプト、参照画像、生成日、利用条件を1表にまとめる。
2. 外部公開前に生成素材の商用利用・再配布範囲を確認。
3. OGPのPNG版を作成し、SNSデバッガーで確認。
