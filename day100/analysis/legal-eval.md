# Day100 法務評価

評価日: 2026-05-05  
スコア: **70 / 100**

## 良い点

- 特商法/プライバシーrouteがあり、フッターから到達できる。
- 事業者名、所在地、電話番号などを捏造せずplaceholderとして明示している。
- 料金・キャンセル条件は「正式確認後」として未確定情報を混ぜない方針。
- 実績、口コミ、保証の捏造は見つからない。

## 指摘

| 優先度 | 内容 | 影響 |
|---|---|---|
| P1 | 事業者情報/所在地/電話/メールが未入力 | 公開不可 |
| P1 | 支払い方法、キャンセル/返金、納品条件が未確定 | 有償申込導線では重大 |
| P2 | プライバシーの問い合わせ窓口が未確定 | 個人情報対応の窓口不足 |
| P2 | GA4導入時のCookie/解析記載が未確定 | 計測開始時に更新が必要 |

## 優先改善

1. 公開前に正式な特商法情報を入力。
2. 料金ページの内容と契約/キャンセル条件を照合。
3. GA4を有効化する場合はプライバシーポリシーを更新。
