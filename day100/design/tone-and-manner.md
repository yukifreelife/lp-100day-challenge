# Tone and Manner v2

## Brand Premise

サービス名: みちしるべ整理室

完全予約制の小さな個人サービスを一人で回す人のために、問い合わせ前後の案内、メニュー、料金、予約導線、当日案内、継続提案を「ひとりでも回る受付導線」に整理する相談サービス。

主CVは「無料30分 受付導線診断」。売上を煽るのではなく、予約が入る前後で詰まっている受け皿を整える。

## Target User

中心人物は `persona-v2.md` の佐伯まどか。

- 個人サロン、教室、相談業などをひとりで運営している
- 予約とリピートはあるが、案内や導線が場当たり的になっている
- LINE返信、料金表、予約フォーム、当日案内、継続案内が散らばっている
- 強い売り込みはしたくないが、自然に次の選択肢を出せるようにしたい
- きれいな資料を作る前のメモ状態から相談したい

## Core Message

予約が入る前後のごちゃごちゃを、ひとりでも回る受付導線へ。

## Visual Concept

**受付導線のカルテ棚**

旧デザインの「地図」モチーフは残すが、抽象的な運営地図ではなく、個人サロン・教室の実務に寄せる。

- カルテ棚: 顧客対応、当日案内、継続案内の分類
- 受付カウンター: 初回問い合わせから予約確定までの流れ
- 予約ルート線: LINE、予約フォーム、カレンダー、当日案内をつなぐ
- メニュー札: 体験、単発、継続の違いを整理
- 小さな付箋: まだ言語化できていない不安
- チェック印: 公開前に確認する条件や抜け漏れ

画面を見た瞬間に「サロン/教室/相談業の予約まわりの整理だ」と伝わることを優先する。

| Accent | ふせんライム | `#B7C957` | 小さなチェック、分類ラベル、注目点 |
| CTA | 予約コーラル | `#D86642` | 主CTAのみ |

Color ratio guide:

- 68%: カルテ白 / 受付紙
- 14%: 受付インクグリーン
- 7%: 薄よもぎ / カルテ罫線
- 5%: 予約プラム
- 4%: ふせんライム
- 2%: 予約コーラル

予約コーラルはCTA専用。装飾には使わない。

## Typography

- Headline: `Shippori Mincho` または近い日本語明朝。静かだが芯のある言葉に使う。
- Body: `Noto Sans JP` 系。短い実務文で読みやすくする。
- Labels: 角丸の小ラベルではなく、カルテ見出し、受付番号、チェック項目のように見せる。

Headline tone:

- やさしい励ましではなく、具体的な詰まりを言い当てる。
- 「運営」より「予約前後」「LINE返信」「メニュー」「当日案内」など実務語を入れる。

## Copy Tone

Preferred:

- 予約が入る前後のごちゃごちゃを、ひとつの受付導線へ
- LINE返信、料金表、当日案内を、迷わず渡せる形に
- 売り込む前に、受け皿を整える
- 体験・単発・継続の違いを、初めての人にも選びやすく
- まだメモのままで大丈夫です

Avoid:

- 何でも整理します
- あなたらしいビジネスへ
- 売上アップ
- 経営課題を解決
- 業務効率化を実現

## Page Rhythm

1. Hero: 予約前後の混乱を言い当て、無料30分診断へ誘導。
2. Problem: LINE返信、料金表、当日案内、継続提案の散らばりを具体化。
3. Map: 問い合わせから継続案内までの受付導線を見せる。
4. Service: メニュー整理、返信テンプレ、予約導線、当日案内、継続案内に分解。
5. Output: 相談後に受け取るものを具体的に表示。
6. Fit: 向いている人 / 向いていない人。
7. Contact: まだ整理できていない状態で申し込める安心感。

## Imagery and UI Motifs

Use:

- 受付カウンター上のカルテ、予約カード、LINE風の返信メモ、カレンダー、メニュー札
- route line connecting `LINE -> 予約 -> 当日案内 -> 継続`
- slim filing tabs and case labels
- small lime sticky note markers
- realistic but clean editorial illustration, not cute stationery

Avoid:

- 汎用ビジネスマップ
- 抽象的なダッシュボード
- generic office stock imagery
- ふわっとした女性向けサロン風だけの装飾
- 過度なベージュ、手帳、カフェ感

## CTA Style

Primary CTA:

- `無料30分 受付導線診断を予約する`

Secondary CTA:

- `予約前後の詰まりを見る`
- `相談で整えるものを見る`

CTA should feel like a safe diagnostic, not a sales call.

## Mockup Direction

The next mockups should look more specific than the current site:

- The hero must include visible terms such as `LINE返信`, `料金表`, `当日案内`, `継続案内`.
- The main visual should show a reception-flow board, not a generic map.
- Page sections should have labels like `受付 01`, `導線 02`, `カルテ 03`.
- Copy blocks should be short and concrete.
- The design should be calm but sharper, with plum and lime accents to avoid becoming another green consulting LP.
