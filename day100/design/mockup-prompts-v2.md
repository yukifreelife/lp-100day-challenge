# Mockup Prompts v2

## Shared Direction

Use case: `ui-mockup`
Asset type: Japanese landing page mockup
Brand: `みちしるべ整理室`
Persona: reservation-based solo service owner, represented by `persona-v2.md`
Core message: `予約が入る前後のごちゃごちゃを、ひとりでも回る受付導線へ。`
Visual concept: `受付導線のカルテ棚`

Palette:

- `#203D36` reception ink green
- `#6E4F68` reservation plum
- `#B7C957` sticky-note lime
- `#D86642` reservation coral CTA
- `#F8FAF4` chart white
- `#FFFFFF` surface
- `#EDF2E6` pale yomogi
- `#D3D9CC` chart line

Common constraints:

- Japanese UI only.
- High-fidelity web UI mockup, not a poster.
- Do not use generic SaaS dashboard visuals.
- Do not use stock-photo-like office teams.
- Use DOM-like sections, cards, forms, tabs, route lines, and realistic Japanese LP spacing.
- Main motif is reception flow: LINE reply, menu card, booking calendar, day-of guide, continuation offer.
- Text should be short and readable; avoid tiny body copy.
- Avoid full beige stationery or cafe-like mood.

## Full Page Mockup

Text to emphasize:

- `予約が入る前後のごちゃごちゃを、ひとつの受付導線へ。`
- `LINE返信、料金表、当日案内、継続案内を迷わず渡せる形に。`
- `無料30分 受付導線診断を予約する`

Sections:

1. Hero with reception-flow board.
2. Problem cards: `LINE返信が長い`, `料金表が散らばる`, `継続案内が怖い`.
3. Route map: `問い合わせ -> 予約確定 -> 当日案内 -> 継続提案`.
4. Outputs: `受付導線図`, `返信テンプレ`, `メニュー整理表`.
5. Fit / not-fit.
6. Contact CTA.

## Service Page Mockup

Focus:

- Service menu as file tabs and reception cards.
- Categories: `メニュー整理`, `LINE返信`, `予約導線`, `当日案内`, `継続案内`.
- Show output cards rather than generic feature cards.

## Contact Page Mockup

Focus:

- Consultation form feels safe.
- Side panel shows `相談前の準備は不要`, `メモのままでOK`, `売り込みなし`.
- Form fields: name, email, current service, scattered point, consultation method.

## Pricing Page Mockup

Focus:

- Pricing plans framed as diagnostic depth.
- Plans: `無料診断`, `受付導線ミニ整理`, `予約前後まるごと整理`.
- Avoid aggressive discounts.

## FAQ Page Mockup

Focus:

- Anxiety-specific FAQ.
- Categories: `相談前`, `料金`, `LINE返信`, `予約導線`, `継続案内`.
- Include question cards: `まだ整理できていなくてもいいですか？`, `強い売り込みになりませんか？`.
