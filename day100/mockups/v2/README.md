# Mockups v2

## Purpose

These mockups replace the earlier broad solo-business direction with a more specific persona and tone:

- Persona: reservation-based solo service owner
- Core problem: messy flow before and after bookings
- Visual concept: `受付導線のカルテ棚`
- Primary CTA: `無料30分 受付導線診断を予約する`

The mockups are references for the next React + Tailwind reconstruction phase. They must not be used as one flattened page background.
