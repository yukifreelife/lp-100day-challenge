## 必要な画像

### ヒーロー用
- `hero.webp` - メインビジュアル（1920x1080推奨）

### メニュー用
- `pasta.webp` - パスタ料理（800x600推奨）
- `pizza.webp` - ピザ（800x600推奨）
- `carpaccio.webp` - カルパッチョ（800x600推奨）
- `dessert.webp` - デザート（800x600推奨）

### 店内・雰囲気用
- `interior.webp` - 店内写真（1920x1080推奨）
- `chef.webp` - シェフ写真（800x800推奨）

### SNS・その他
- `ogp.png` - OGP用画像（1200x630推奨）
