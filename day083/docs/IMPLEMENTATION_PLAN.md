## 1. カラーパレット案

### イタリアンをイメージする暖色系

```css
:root {
  /* メインカラー - トマト/ワインレッド */
  --color-primary: #D32F2F;
  --color-primary-dark: #B71C1C;
  --color-primary-light: #E53935;
  
  /* セカンダリーカラー - オリーブオイルゴールド */
  --color-secondary: #F9A825;
  --color-secondary-dark: #F57F17;
  
  /* アクセントカラー - バジルグリーン */
  --color-accent: #388E3C;
  
  /* ニュートラルカラー - クリーム系 */
  --color-cream: #FFF8E1;
  --color-sand: #F5F5DC;
  --color-warm-white: #FFFEF9;
  
  /* テキストカラー */
  --color-text: #3E2723;
  --color-text-secondary: #6D4C41;
  
  /* ボーダー・背景 */
  --color-border: #E0E0E0;
  --color-bg: #FFFEF9;
}
```

### 色の使分け
- ヒーロー・CTA: メインカラー（ワインレッド）
- サブ要素・ポイント: セカンダリー（ゴールド）
- アクセント・健康イメージ: アクセント（グリーン）
- 背景: ニュートラル（クリーム系）で温かみを演出

## 2. セクション構成案

### 飲食店向けに最適化された構造

| セクション | 目的 | コンテンツ |
|-----------|------|-----------|
| **Hero** | 第一印象・来店動機 | - 店内雰囲気画像（メインビジュアル）<br>- キャッチコピー「家族で楽しむ本場イタリアの味」<br>- 予約ボタン<br>- 雰囲気を伝える短いリード文 |
| **About** | お店のこだわり紹介 | - イタリア人シェフの紹介<br>- 直輸入食材のこだわり<br>- 本格レシピへの想い |
| **Menu** | メニュー紹介 | - 人気メニュー3品（ピザ、パスタ、子供向け）<br>- 価格帯表示<br>- アレルギー対応の有無 |
| **Gallery** | 雰囲気・お料理画像 | - 店内の様子（テーブルセッティングなど）<br>- お料理の美味しそうな写真<br>- 家族連れが楽しんでいる様子 |
| **Voice** | お客様の声 | - 家族連れの口コミ3件<br>- Googleマップ評価<br>- 「子供も楽しめる」「本場の味」等のキーワード |
| **Access** | アクセス・店舗情報 | - 地図（埋め込み）<br>- 住所・電話<br>- 営業時間・定休日<br>- 駐車場情報（家族連れに重要） |
| **FAQ** | よくある質問 | - 子供連れOK？<br>- アレルギー対応？<br>- コース料理は？<br>- プライベート席は？ |
| **Reservation** | 予約・お問い合わせ | - 電話予約ボタン<br>- Web予約フォーム<br>- Googleマップ予約リンク |

## 3. コピーライティングの方向性

### 家族連れ向け

**基本トーン**
- 温かみのある語り口
- 「ご家族」「お子様」といった言葉選び
- 安心感・親しみやすさ

**キーワード**
- 子供も喜ぶ
- 広々とした店内
- お子様メニュー
- アレルギー相談OK
- 駐車場完備
- ゆっくり食事を

### 本場の味（イタリアン）

**基本トーン**
- 本物へのこだわり
- シェフの想い
- 食材への敬意

**キーワード**
- ナポリ出身シェフ
- 現地直輸入
- 本格レシピ
- 手打ちピザ
- トラディショナル
- イタリアの味

### キャッチコピー案

**メイン**
1. 「家族で楽しむ、本場イタリアの味」
2. 「お子様も大人も、イタリアンの旅へ」
3. 「ナポリの太陽を、日本の食卓に」
4. 「Trattoria Sole - 家族の絆、食の絆」

**サブ**
- 「イタリア人シェフが届ける、心温まる本格イタリアン」
- 「お子様からご年配の方まで、皆さまに愛されるトラットリア」
- 「手打ちピザと本格パスタで、家族の食卓を彩る」
