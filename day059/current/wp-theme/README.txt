製造業向け採用支援サービス LP テーマ

== Description ==

ミチル採用企画向けの製造業採用支援サービスLPテーマです。

特徴:
- スマホファーストのレスポンシブデザイン
- 落ち着いたアニメーション
- OGP/Twitter Card対応
- Contact Form 7対応

== Installation ==

1. wp-content/themes/ ディレクトリにこのフォルダをアップロード
2. 管理画面 > 外観 > テーマ で「LP Manufacturing Recruitment」を有効化
3. 固定ページを作成してテンプレートを適用
